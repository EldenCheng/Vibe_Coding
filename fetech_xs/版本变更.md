# 版本变更记录

## v2.1.6 (2026-10-08) — 卷/节结构老帖 + 6park 水印清理

**背景**：《校园枫叶红》（tid=71454，2012年老帖）主贴只有简介，章节在跟贴里，
跟贴标题「第X节　标题（N-M）」（括号内是节内小节号，非全局章号），
帖内用「第X节　标题（N上/下）」标题行分小节——全新的章节组织形态。

- **节帖识别**：跟贴过滤新增 `_SECTION_SUBJECT_RE`（第X节开头；卷分隔帖「第X卷」无正文不抓）
- **小节切分**：`_SECTION_HEAD_RE` 识别帖内标题行（`（N）/（N上/下）/（上/下）`，
  全半角数字、空格随意；标题可能与上一段粘在一起，不要求行首边界；
  括号内是范围（如１－５）的不误匹配）。每个小节一章，章节号用帖内顺序，
  全局排序靠 tid+帖内顺序；无标题行的节帖整帖一章
- **同名小节去重**：作者重复粘贴的同名小节（内容相同）保长版去重；
  同名但内容不同（作者标题贴错的续段）保留不丢内容
- **老帖噪声清理**：`_to_paragraphs` 剥除 6park 水印（老帖每段之间都有）与版主编辑记录
- **主贴书名**：《书名》（１－２卷５节２小节）形态的结构描述范围不会被误用
  （主贴无章节标记，不参与切章）
- 验证：《校园枫叶红》→ 31 个节帖切出 **209 章全部可下载 + EPUB**（源帖缺十节(5-7)一帖，
  非下载器问题）；新增离线测试 test_cool18_section.py；全部既有回归通过

## v2.1.5 (2026-10-08) — 《书名》（全）主贴 + 裸范围跟贴标题

**背景**：《爹爹，我要和你双修！》（tid=13879264）主贴只有内容简介，章节在跟贴里，
但跟贴标题是裸范围（`01-24`…`159-171（终）`），主贴书名用 `《》` 而非 `【】`，
之前的判定都套不上。

- **标题解析扩展**：`_parse_title` 支持 `《书名》（全）` 主贴形态；
  无书名括号时识别裸范围标题（如 `01-24`、`159-171（终）`、`40 完`）返回 (None, 范围)
- **跟贴过滤扩展**：新增 `_BARE_RANGE_RE`，与 `_LIST_CHAPTER_RE` 双判定 ——
  裸范围跟贴能抓到，闲聊/评分噪声照常过滤
- 范围提取、`（终）`/`完` 后缀、全角补零标记（`第００１章`）沿用现有逻辑
- 注意：作者跟贴标题范围可能写得偏宽（如标题 24-47 但正文从 25 开始，上一帖末尾已有 24），
  重复章由现有的内容相似去重处理
- 验证：《爹爹，我要和你双修！》→ 8 个跟贴帖切出 **171 章（1-171 无缺无重）全部可下载 + EPUB**；
  离线测试新增 test_cool18_bare.py；回归 小流氓/苏浅柔×2/Q书/认贼作父/父女圣约/束缚成蝶/
  作者限定/search.php/柔情肆水×2/跟贴章节帖/管理器 smoke 全过

## v2.1.4 (2026-10-08) — 跟贴章节帖 + 标题行标记 + 换行归一化

**背景**：《凌辱之一生性奴》（tid=13865560）主贴正文为空，章节全在跟贴里，
之前跟贴被过滤导致 0 章。

- **跟贴宽松判定**：`_fetch_replies` 不再要求「作者」后缀，改用宽松的「【书名】（范围）」
  判定（`_LIST_CHAPTER_RE`），评分/灌水噪声照常过滤 → 章节型跟贴（含 `（16-19）全文终`）能抓到了
- **标题行标记**：识别「书名/标签在前、第X章在行尾」的标题行（如
  `凌辱之一生性奴（校园，凌辱，痴女，女主视觉） 第十七章`），行内含（、【或已知书名才认；
  书名被截断（少「凌」字）也能识别 → 恢复 17 章等
- **合并重复标记**：标题行 第X章 + 独立 第X章 两连发 → 紧邻保留后一个（正文干净）；
  相隔远（前章正文范围内的重复标记）→ 丢弃后一个 → 「第一章标题行 + 契子 + 重复第一章」
  能保住契子（第1章从契子开始，无重复标记残留）
- **换行归一化**：`_to_paragraphs` 统一 `\r\n`→`\n`、按空行切段（LF 分隔的书整章不再是一大段），
  避免 Windows 写入时 `\r\r\n` 双转换
- 修复 _MARK_RE/_SPECIAL_RE/_CHAPTER_EN_RE 里「章→小标题」的 `\s*` 贪婪吃换行问题
  （正文第一行被误当小标题）
- 验证：《凌辱之一生性奴》→ 跟贴 6 帖切出 **19 章（1-19，19=终篇）全部可下载 + EPUB**；
  回归 小流氓/苏浅柔×2/Q书/认贼作父/父女圣约/束缚成蝶/作者限定/search.php/柔情肆水×2/管理器全测 全过

## v2.1.3 (2026-10-08) — 多格式标记支持（全角数字/括号标记/完后缀/前缀拯救/外传整章）

**背景**：《柔情肆水》主线 1-60 章每章单独发帖，作者格式极不统一，修复前 48 章缺失/乱序/重复。

- **全角数字 `０-９` 加入所有标记正则**：`第１７章`、`第２７章`、`第３１章` 等现在能识别
  （恢复 6-13、17、18、27、31 章及小标题；重复第30章随 31 章被正确切出后自动去重）
- **括号包裹的标记**：`（第47章 池中鸳鸯）（中）`、`（第52章 禁欲的终结）` → 恢复 47、52；
  小标题整理（`） （中）` → `（中）`；`嘴巴的开发（上）` 这类配对括号不被误剥
- **标题范围兼容「完/完结」后缀**：`60完` → [60]，单章帖整篇兜底 → 恢复第60章
- **范围帖前缀拯救**：范围帖开头章节没写标记时，把第一个标记前的正文按范围首章号兜底
  → 恢复 14（实为全角）、45、53、57 章；主贴(1-60)等不缺开头的不误伤
- **外传帖整章**：标题范围含「外传」的帖子整帖作为一章（标题用外传名，去「完」后缀），
  不再按内部标记切章 → 消除外传第7/8章与主线撞号；外传单章排在主线之后
- **正文头部剥离**：兜底/外传/前缀拯救生成的章节会剥掉「【书名】（范围）作者：…日期…」头部
- 验证：《柔情肆水》全角作者组 → **主线 1-60 完整有序 + 10 个外传单章 = 70 章**；
  半角作者组（纯外传 21 帖）也能正常下载了；回归 小流氓/苏浅柔×2/Q书/认贼作父/父女圣约/
  束缚成蝶/作者限定/search.php/管理器全测 全过

## v2.1.2 (2026-10-06) — 支持 search.php 全站搜索入口

- **新增 search.php 搜索入口**：`cool18.com/search.php?keyword=…&sa=…`（全站搜索）
  之前只认 threadsearch/action=search，search.php 会误走 thread 模式导致 0 章
- 结果列表兼容两种结构：threadsearch 的 `ul.post-list.thread-list` 与 search.php 的

- 帖子链接直接用搜索结果里的绝对 URL（search.php 在站点根，旧逻辑拼 base 会拼出错的 /index.php）
- 分页：threadsearch 用 `a.next`；search.php 用数字分页 `?p=N`（取最大页码逐页跟进）
- `keyword`（单数）参数与 `keywords` 都支持；管理器 `find_by_identity` 同步支持 `keyword=` 反查
- 验证：《我穿上乳环和阴蒂珠被作为祭品献给冬神》search.php 入口 → 17/17 章 + EPUB；

  是否存在于磁盘；章节表更新后旧文件（索引被占用但标题不同）会被识别为过期并自动清理，

## v2.0 (2026-10-01) — 多站点支持（架构重构）

背景：新增 cool18.com（论坛型小说站）支持。两站工作流差异巨大（目录页 vs 帖子切章），
经用户确认采用「站点适配器」架构，而非「一套脚本 + 每站配置」。

- **架构重构**：新增 `sites/` 目录（`base.py` 适配器基类 + `alice_book.py` + `cool18.py`）；
  `download_novel.py` 保持入口签名（URL/book_id + `--rd`/`--check`/`--output-dir`）不变，
  内部按 URL 域名分发到站点适配器 → **下载管理器 `fetch_xs.py` 适配层零改动**（除 §补强）
- **新增 cool18 适配器**（论坛型）：
  - 4 种章节来源：① 作者在正文里维护的列表链接 ② 跟贴发布章节（`achildlist` AJAX 接口）
    ③ 单帖 ④ 搜索页（threadsearch，逐页翻页）
  - 章节切分：`第X章+小标题` / `第X章【字数】` / 裸数字段落 / 尾部番外 / `=====` 分隔线
  - 章节号中文/阿拉伯/全角数字统一；标题噪声清理（书名重复、纯数字残留）
  - 按章节号 + 内容完整度去重（丢弃被截断的预告，取完整版）
  - 顺序由作者章节号驱动（番外紧跟所属章），EPUB 不会前后错乱
  - **章节顺序改为按“发布时间”（tid）排**：作者编号常随心所欲（如 12-13 之后是
    2.1-2.3），按编号排会乱；发布时间才是真实阅读顺序
  - 卷号容忍：标题范围带同卷号（`2.1-2.3`）时给正文的“第1/2/3章”补上卷前缀
    （→ 第2.1章…）；跨卷合集（`1.0-2.3`）不补
  - 去重改为“内容相似度”：仅当同号章节内容高度相似（节选/预告/极短占位/近乎重发）
    才保留完整版；卷号不同的同号章节都保留
  - 正文只取 `<pre>`，避开 `</pre>` 之后的广告/AI标记/脚本混入正文
  - 新增“全角空格 + 4 位补零数字 + 紧跟标题”标记识别（如 `　　0073她成为…`，
    章节号与标题间无分隔符、无“第X章”）；要求前导 0 避开正文年份等普通数字
  - 新增“全角空格 + 数字 + 「、」 + 标题”标记识别（可被 `<strong>` 包裹，如
    `　　<strong>1、十事神谕</strong>` / `　　35、归心`）；用顿号与正文枚举列表（`1.`）区分
  - 切章前去掉行内 `<strong>`/`<b>` 标签（否则被包住的章标记识别不到）；章标题后
    紧跟换行（而非 `<p></p>`）也算合法终止符
  - 特殊章名（序章/序幕/幕间/终章/尾声）单独成章；可带「第X卷」前缀
  - **书名目录名做 Windows 非法字符处理**（半角 `\ / : * ? " < > |` → 全角），
    否则如《阴胎真经:奼女孕奴录》（半角冒号）会在 Windows 上 `mkdir` 失败；
    download_novel.py 与 build_epub.py 用同一套规则保证目录一致
  - 作者名优先取 h1，h1 未写`作者：`时回退到正文头部（如“认贼作父…”h1 只有
    “迪斯马的头”，正文头才是全名“迪斯马的头颅”）
- **config.json 新增 `sites.<站点>` 覆盖段**：可对特定站点覆盖 proxy / request_delay / headers
  （cool18 常需独立代理）；未配置时用全局默认
- **sanitize_filename 改进**：纯「第X章」标题不再退化成 hash 文件名（改为保留原标题）
- **--check 语义确认**：每次重新抓取入口 URL 重建章节表，可与磁盘对比**发现同一入口下
  新增的章节**（写入 failed，再 `--rd` 补下）；该机制对两个站点都生效
- **修复“章节表更新后新章节下不下来”**：正常下载与 --check 均改为按「期望文件名」
  （`{index:04d}_{清洗后标题}.html`）核对磁盘，而非只看索引/只看 `status==complete`。
  否则旧文件恰好占用相同索引（如识别修复后章数从 3 变 17）会被误判为已完成，
  且旧版会因 stale 的 `status==complete` 直接退出。同时自动清理 stale 旧文件
- **管理器补强（fetch_xs.py）**：`find_by_identity` 支持按 `tid=` / `keywords=` / 完整 URL
  反查 cool18 书目录（重跑已存在书不再误报「已完成(未核实)」）
- **已知限制**：cool18 必须走代理；图片只保留文件名文本不抓图；thread 模式只覆盖
  「主贴 + 列表 + 一级跟贴」，更深嵌套回复需用搜索模式；cool18 的 `--check` 会重新抓
  全部帖子（耗时较长属正常）
