# 计划书 —— 沪深300成分股财务数据采集程序

## 项目概述

自动从东方财富网采集沪深300成分股的单季度财务数据（每股收益、现金流、营收、利润等），保存为CSV原始数据，并生成带排序功能的HTML季度报表。

---

## 程序架构

```
fetech_hs300_detail/
├── main.py              # 主程序入口，编排完整采集流程
├── config.py            # 集中配置：API地址、请求头、字段映射、延时参数
├── hs300_fetcher.py     # 获取沪深300成分股列表（东方财富datacenter API）
├── finance_fetcher.py   # 获取单只/全部股票的财务数据（东方财富F10 API）
├── csv_exporter.py      # CSV导出（单股文件 + 汇总文件两种模式）
├── html_generator.py    # HTML报表生成（按季度分别生成）
├── html_template.py     # HTML模板（CSS样式 + JS排序功能）
├── utils.py             # 工具函数（日期计算、市场前缀判断、安全取值）
├── analyze.py           # 离线分析脚本（从已保存CSV重新生成HTML）
├── __init__.py          # 包标识（空文件）
├── 提示词.txt            # 原始对话提示词
├── 计划书.md            # 本文件
└── 版本变更.md           # 版本变更记录
```

## 模块职责与依赖关系

### main.py — 主程序入口
- **职责**: 编排完整采集流程（5步）
- **流程**:
  1. 调用 `hs300_fetcher` 获取300只成分股列表
  2. 调用 `utils.get_query_dates()` 计算目标季度日期
  3. 调用 `csv_exporter.get_save_dir()` 准备存储目录
  4. 调用 `finance_fetcher.fetch_all_finance()` 逐只获取财务数据，每完成一只即时保存CSV
  5. 调用 `html_generator.generate_all_html()` 按季度生成HTML报表
- **依赖**: hs300_fetcher, finance_fetcher, csv_exporter, html_generator, utils

### config.py — 配置中心
- **职责**: 集中管理所有可配置参数
- **内容**:
  - `HEADERS`: HTTP请求头（User-Agent, Referer, Accept）
  - `FINANCE_API_TEMPLATE`: 财务数据API URL模板
  - `SLEEP_MIN / SLEEP_MAX`: 请求间随机延时范围（5~10秒）
  - `RAW_DATA_DIR`: 原始数据存储目录名
  - `HTML_COLUMNS`: HTML表格列定义
  - `FINANCE_FIELD_MAP`: API字段→内部字段映射
  - `SHANGHAI_PREFIXES / SHENZHEN_PREFIXES / BEIJING_PREFIXES`: 市场前缀判断规则

### hs300_fetcher.py — 成分股获取
- **职责**: 从东方财富datacenter API获取沪深300成分股列表
- **API**: `https://datacenter.eastmoney.com/api/data/v1/get?reportName=RPT_INDEX_TS_COMPONENT`
- **输出**: list[dict]，每项包含 code, name, industry, region, market_prefix
- **依赖**: config.HEADERS, utils.get_market_prefix

### finance_fetcher.py — 财务数据获取
- **职责**: 逐只调用东方财富F10 API获取单季度财务数据
- **API**: `https://emweb.securities.eastmoney.com/PC_HSF10/NewFinanceAnalysis/ZYZBAjaxNew?type=2&code={code}`
- **核心函数**:
  - `fetch_single_stock_finance()`: 获取单只股票各季度财务数据
  - `fetch_all_finance()`: 遍历全部成分股，内置延时控制和回调机制
- **延时策略**: 每获取一只股票后随机暂停5~10秒，最后一只不延时
- **依赖**: config (API URL, 字段映射, 延时配置), utils.safe_get

### csv_exporter.py — CSV导出
- **职责**: 将采集数据保存为CSV文件
- **存储结构**: `OriginalData/YYYY-MM-DD/` 按日期分目录
- **两种模式**:
  - `export_stock_to_csv()`: 每只股票一个独立CSV（主流程使用）
  - `export_all_to_csv()`: 全部股票汇总到一个CSV（备用）
- **文件名格式**: `{股票代码}_{股票简称}.csv`

### html_generator.py — HTML报表生成
- **职责**: 按季度分别生成带排序功能的HTML表格
- **输出**: `YY-MM-DD.html`（如 26-03-31.html），存放于程序运行目录
- **依赖**: config.HTML_COLUMNS, html_template

### html_template.py — HTML模板
- **职责**: 提供完整的HTML/CSS/JS模板
- **功能**: 表头可点击排序（升序→降序→恢复原始顺序）
- **金额显示**: ≥1亿以"亿"为单位，<1亿保留原数字
- **特殊处理**: "N"值（无数据）排序时排到最后

### utils.py — 工具函数
- **职责**: 通用辅助函数
- **核心函数**:
  - `get_query_dates()`: 根据当前日期计算需查询的季度（最多5个）
  - `get_short_date()`: YYYY-MM-DD → YY-MM-DD（用于文件名）
  - `get_market_prefix()`: 股票代码 → 市场前缀(SH/SZ/BJ)
  - `safe_get()`: 安全字典取值

### analyze.py — 离线分析脚本
- **职责**: 从已保存的CSV文件读取数据，重新生成HTML报表
- **场景**: 原始数据采集失败/中断后，无需重新下载即可生成报表
- **用法**:
  - 无参数: 扫描 `OriginalData/` 最新子目录
  - 有参数: 使用指定目录

## 数据流

```
东方财富API
    ↓
hs300_fetcher → 成分股列表 (300条)
    ↓
finance_fetcher → 逐只获取财务数据（带5-10秒延时）
    ↓
csv_exporter → OriginalData/YYYY-MM-DD/{code}_{name}.csv (即时保存)
    ↓
html_generator → YY-MM-DD.html (按季度分文件)
```

## API接口说明

| API | 用途 | 参数 |
|-----|------|------|
| datacenter.eastmoney.com/api/data/v1/get | 获取沪深300成分股列表 | TYPE=1, pageSize=300 |
| emweb.securities.eastmoney.com/PC_HSF10/NewFinanceAnalysis/ZYZBAjaxNew | 获取单季度财务指标 | type=2(单季度), code=市场前缀+代码 |

## 日期计算逻辑

根据当前电脑日期的月份确定查询范围：

| 当前月份 | 查询季度 |
|----------|----------|
| 1-3月 | 上年Q4, Q3, Q2, Q1（4个） |
| 4-6月 | 当年Q1 + 上年Q4, Q3, Q2, Q1（5个） |
| 7-9月 | 当年Q2, Q1（2个） |
| 10-12月 | 当年Q3, Q2, Q1（3个） |
