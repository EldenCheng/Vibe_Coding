# 版本变更

## v0.1.0 (2026-10-08)

首个版本。从一次性脚本 `kvmem_download.py`（会话中临时写的 kvmem 运行包下载脚本）通用化而来。

- 单 URL HTTP(S) 直链下载，文件平铺到 `Download/`
- 断点续传：单流 `.part` 追加 + Range；分块模式按确定性段边界拆分，逐段续传
- 多线程分块下载：`concurrency`（默认 4），小文件/服务器不支持 Range 时自动退回单流
- 限速：`speed_limit_kb` 全局令牌桶，多线程共享总口径
- 哈希校验：`--sha256`（64 位=SHA256 / 32 位=MD5）+ `auto_verify` 自动读同名 `.sha256` sidecar；完成必记 `actual_sha256`
- 代理：`proxy` 留空 = 读操作系统代理（与其它下载器语义一致），管理器中不遮罩
- 自定义请求头 `headers`、超时、指数退避重试
- 重名处理：`rename` / `overwrite` / `skip`
- `progress.json` sidecar（`Download/.progress/`）+ 固定 stdout 锚点行，供统一下载管理器适配
