# OpenCode 项目设计文档

## 1. 项目概述
本目录存放与 OpenCode 配置相关的设计与变更记录。

## 2. 已实施功能

### 2.1 免费搜索功能（2026-09-14）

**需求来源：** 用户反馈 OpenCode 有免费搜索功能但需设置才能开启，要求协助开启。

**方案选型：**
调研了 3 种免费方案：
- **A. 内置 Exa/Parallel 托管搜索（已采用）**：设置 `OPENCODE_ENABLE_EXA=1` 即可使用官方托管的 Exa MCP (`https://mcp.exa.ai/mcp`)，无需 API Key，所有模型通用，对应文档 `opencode.ai/docs/tools#websearch`。适合当前版本 `1.18.0`。
- B. `opencode-websearch` 插件：依赖模型自带联网能力（Anthropic/OpenAI/Moonshot/xAI），需配置对应 provider。
- C. `opencode-search` 插件：DuckDuckGo/Wikipedia 等直爬，完全免费但稳定性一般。

用户选择 **方案 A + 全局生效**。

**设计细节：**
- **配置文件：** `C:\Users\automation\.config\opencode\opencode.jsonc`（全局，优先级高于远程、低于项目）
  - 新增 `permission` 字段：
    ```jsonc
    "permission": {
      "websearch": "allow",
      "webfetch": "allow"
    }
    ```
  - `allow` 表示自动执行，无需每次 `ask` 确认；如需收紧可改为 `ask`。
- **环境变量：** `OPENCODE_ENABLE_EXA=1`
  - 永久写入：`[System.Environment]::SetEnvironmentVariable("OPENCODE_ENABLE_EXA","1","User")`（Windows 用户级环境变量）
  - 当前进程同时设置：`$env:OPENCODE_ENABLE_EXA="1"`
  - 替代变量：`OPENCODE_ENABLE_PARALLEL=1` 或 `OPENCODE_EXPERIMENTAL_EXA=true` 效果等同，但推荐 `OPENCODE_ENABLE_EXA` 最小化启用范围
  - 验证逻辑：`Flag.OPENCODE_ENABLE_EXA = truthy("OPENCODE_ENABLE_EXA") || Flag.OPENCODE_EXPERIMENTAL || truthy("OPENCODE_EXPERIMENTAL_EXA")`，进而启用 `websearch` 与 `codesearch` 两个工具
- **权限验证：** `opencode debug config` 可查看合并后配置；`opencode run "websearch 测试"` 可验证工具是否出现
- **生效范围：** 全局对所有项目生效，无需在 `Vibe_Coding\.opencode\` 下重复配置

**启动方式（Windows pwsh）：**
```powershell
# 临时（当前终端）
$env:OPENCODE_ENABLE_EXA="1"; opencode

# 永久（已执行，新终端自动生效）
[System.Environment]::SetEnvironmentVariable("OPENCODE_ENABLE_EXA","1","User")

# 验证
Get-ChildItem Env:OPENCODE*
opencode debug config
```

**后续升级注意：**
- 若升级到 v2，`permission` 将迁移为 `permissions: [{action:"websearch", resource:"*", effect:"allow"}]`，且搜索配置改为 `websearch: {provider: "exa"}` / `"random"` / `false`，并支持多 provider 轮换与 429 冷却重试。
- 如需关闭：`"websearch": false` 或删除环境变量 ` [System.Environment]::SetEnvironmentVariable("OPENCODE_ENABLE_EXA",$null,"User")`。

## 3. 目录结构
```
C:\Users\automation\.config\opencode\
  opencode.jsonc      # 全局运行时配置（含 provider、permission、plugin）
  opencode.json       # 旧版兼容（若存在）
  tui.json            # TUI 主题/快捷键配置
  plugins/            # 本地插件（可选）
```
