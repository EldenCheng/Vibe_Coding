# 版本变更

## v2026.09.14 - 启用免费搜索功能

**变更类型：** 配置新增

**变更内容：**
- 全局配置 `C:\Users\automation\.config\opencode\opencode.jsonc` 新增 `permission.websearch=allow` 与 `permission.webfetch=allow`
- 系统用户环境变量新增 `OPENCODE_ENABLE_EXA=1`（永久），进程级同步设置
- 验证通过：`opencode run` 触发 `Exa Web Search` 成功返回 `OpenCode v1.18.30` 等结果；`webfetch` 抓取 `opencode.ai/docs/tools` 成功

**影响范围：** 全局，所有项目启动 `opencode` 时自动获得 `websearch`/`webfetch` 工具，无需额外 API Key（走官方托管 Exa MCP `https://mcp.exa.ai/mcp`）

**回滚方式：**
```powershell
[System.Environment]::SetEnvironmentVariable("OPENCODE_ENABLE_EXA",$null,"User")
# 并从 opencode.jsonc 移除 permission.websearch/webfetch
```

**后续可选：**
- 如需更细粒度控制，改为 `"websearch": "ask"` 或 v2 语法的 `permissions: [{action:"websearch", effect:"ask"}]`
- 如需多源容灾，可追加 `plugin: ["opencode-search"]`（DuckDuckGo）或 `opencode-websearch`（模型原生搜索）
