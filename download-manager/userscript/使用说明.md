# 发送到下载管理器 · 油猴脚本使用说明

在网页上直接把任务交给本机「统一下载管理器」——不用再切回管理器页面粘贴地址。
支持电子书、E-Hentai 画廊、视频（批量 batch / yt-dlp / m3u8 直链）三类任务，提交后**自动入队开始下载**。

- 脚本文件：`userscript/download-to-manager.user.js`
- 设计依据：《Design/项目设计文档.md》§23
- 配套版本：download-manager v0.4.3（脚本只用管理器**现有**接口，后端没有为它改过一行）

---

## 1. 安装（3 步）

1. 浏览器装 **Tampermonkey**（油猴）扩展。
2. 点油猴图标 → **添加新脚本** → 全选删掉模板内容 → 把 `download-to-manager.user.js`
   全文粘进去 → `Ctrl+S` 保存。
3. 确认脚本已启用（油猴管理面板里「发送到下载管理器」是绿色）。

## 2. 首次配置（只做一次）

点油猴图标 → 在脚本列表里点「**发送到下载管理器**」→ 菜单里选「**管理器设置（地址/令牌）**」：

| 字段 | 填什么 |
| --- | --- |
| 管理器地址 | 管理器跑在同一台机器上就留默认 `http://127.0.0.1:8765` |
| 访问令牌 | 打开 `download-manager/config.json`，复制 `server.access_token` 的值（管理器启动时控制台也会打印） |

填完点「**测试连接**」，出现「连接正常，令牌有效（当前 N 个任务）」就通了。
令牌存在油猴的脚本存储里，**不会过期**，以后不用再填。

> 管理器跑在**别的机器**上（比如 Mac）：把地址改成它的局域网 IP（如 `http://192.168.2.100:8765`），
> 并在 Tampermonkey 里给本脚本补一条 `@connect 192.168.2.100`（首次请求时它一般会主动提示你加）。

## 3. 日常怎么用

在支持的站点打开页面 → 点油猴图标（**图标上的数字表示本页有可用脚本**）→
点「发送到下载管理器」→ 三个菜单项：

| 菜单项 | 作用 |
| --- | --- |
| **下载到管理器…** | 主入口：弹出面板，地址已自动填好当前页，按需改参数后「加入下载」 |
| 管理器设置（地址/令牌） | 改地址/令牌，或点「测试连接」排查 |
| 打开管理器页面 | 新标签页打开管理器（想看队列/进度时用） |

提交成功后，面板底部结果条显示：

```
✓ 已加入任务 #a1b2c3d4 — 排队中（第 2 位）     打开管理器看看
```

- **面板不会自动关闭、表单会保留**，可以直接改地址再点「加入下载」连续提交多个任务。
- **提交任务不会打开任何页面**。「打开管理器页面」是独立菜单项，只有你主动点它才开；
  结果条里那个「打开管理器看看」链接也是点了才开。

## 4. 参数速查

### 电子书 / E-Hentai

| 下载器 | 字段 |
| --- | --- |
| 电子书 | 地址（`book_id` 或章节列表 URL，自动填当前页） |
| E-Hentai | 画廊 URL（自动填当前页）+ 页码范围（留空=全部，如 `1-10,20,30-40`） |

### 视频：三种方式分别要什么

| 方式 | 需要你提供 | 说明 |
| --- | --- | --- |
| 批量下载 batch | 列表页地址 +（可选）集数范围 / 线路或候选 / 每集间隔 | 整季；每集独立工作目录，中断后重跑同一条命令自动续跑 |
| yt-dlp | 只有地址 | B站 / YouTube 等主流站点，纯 HTTP、不开浏览器 |
| 直接下载 get | m3u8 直链（可从 F12 网络面板复制）+ 可选 Referer / Cookie | 最可靠，只下这一个视频 |

### 集数怎么填（batch）

面板上是「**快捷芯片 + 文本框**」：点 `[全部] [1-6] [1-12] [1-24]` 只是帮你**快速填**，
最终以文本框为准，也可以自己写 `1-12,15`。**留空 = 全部集**（会跳过选区确认直接开始）。

- 页码从 **1** 开始，逗号分隔，区间用 `-`。
- 明显错误的写法（`0`、`5-3`、`12-`、`abc`）会在提交前被拦下并提示，不会把坏参数送给下载器。

### 线路 vs 每集候选（脚本会自动替你判断）

这两项**互斥**，面板会按当前站点自动切换，你不需要判断站点类型：

| 站点类型 | 面板显示 | 怎么填 |
| --- | --- | --- |
| **内嵌播放器站点**（`mvffm.net` / `movieffm.net`、`ikanbot.com`——播放页 JS 里直接写着"线路×剧集"直链） | **线路**下拉 | 默认「自动（探活第一条存活线路）」；想强制某条线就选「自定义…」，填 `22` 或 `FLV 22 推薦31` |
| **其它站点**（如 `eacg.net`、`youknow.tv`，需要开浏览器嗅探） | **每集候选**（数字，默认 1） | 某集嗅探到多个 m3u8 时取第 N 个（广告流/其它清晰度都可能被抓到），选错换数字重跑，已完成的集会跳过 |

> 为什么默认「自动」：下载器本来就会**探活**第一条存活线路，某集在主线路失败还会自动换线
> （`sites/*.json` 的 `failover_max`）。所以多数情况下**留空就行**，只有在你想指定线路时才需要选。

## 5. 支持哪些网站（`@match` 白名单）

脚本只在下面这些域名生效（油猴图标才会亮数字），并按域名**自动预选**下载器与方式：

| 域名 | 预选 |
| --- | --- |
| `e-hentai.org` / `exhentai.org` | E-Hentai 画廊 |
| `*.als1004.space`（书站，含 punycode 主机名） | 电子书 |
| `bilibili.com` / `b23.tv` / `acg.tv` / `youtube.com` / `youtu.be` | 视频 · yt-dlp |
| `mvffm.net` / `movieffm.net` / `ikanbot.com` | 视频 · 批量（**内嵌播放器**，面板显示「线路」） |
| `eacg.net` / `javdock.com` / `youknow.tv` | 视频 · 批量（需嗅探，面板显示「每集候选」） |
| 地址本身是 `.m3u8` 直链 | 视频 · 直接下载 get |
| 其它（仅当你自己加了匹配规则） | 视频 · 批量 batch（兜底） |

### 5.1 怎么加一个新站点（维护指南）

**v1.0.2 起，支持站点集中在脚本里的 `SITES` 单表** —— 就是文件里带 `const SITES = [...]`
的那段（`PRESETS` / `EMBEDDED_SITES` / `CAUTION_SITES` 全由它自动派生，**不用再各处改**）。
加一个站点：

**① 改 `SITES` 一行**（大多数站点改这一处就够）：在 `SITES` 数组里加一项，例如

```js
{ hosts: ['newsite.com'], type: 'video', mode: 'batch', label: '视频 · 批量' },
```

字段含义：

| 字段 | 说明 |
| --- | --- |
| `hosts` | 域名后缀数组；子域自动匹配（`'newsite.com'` 也匹配 `www.newsite.com`） |
| `type` | `ebook` / `ehentai` / `video` |
| `mode` | `''` / `'get'` / `'batch'` / `'ytdlp'`（仅 video 有意义） |
| `label` | 面板上显示的预选名 |
| `embedded` | 仅 `video`+`batch`：`true` = 播放页直链（面板给「线路」）；省略 = 需嗅探（给「每集候选」） |
| `caution` | 可选警示文案（下载器拒绝/有坑的站点，面板顶部提示一行，仍可提交） |

**② 补文件顶部的 `@match`**：按现有格式加一行，例如

```
// @match        *://*.newsite.com/*
```

⚠️ 这一步**必须手动**：`@match` 是油猴在加载脚本时就读的元数据，运行时生成不了。
漏掉的话脚本在该网站根本不会运行（图标不亮数字）。

**③ 视频站通常还要给下载器加解析配置**：在 `m3u-get-down/sites/` 加一个 `<站名>.json`
（参考同目录已有的 `youknow.json` / `mvffm.json`）。这是**下载器**用的，和本脚本无关；
不加的话下载器可能认不出该站的播放页结构。

改完自检（会检查 `@match` 与 `SITES` 是否一致，漏改第 ② 步会直接报错）：

```powershell
node userscript/test_core.mjs
```

> 只想临时在某个站用一次：不必改脚本，直接把脚本头部 `// @match        *://*/*` 那行取消备注即可
> （代价是油猴图标在任何页面都会显示脚本数字）。

## 6. 常见问题

**Q：点菜单后提示「连不上管理器」？**
管理器没启动（运行 `start_server.bat` / `./start_server.command`），或地址填错了，
或在别的机器上但没在 Tampermonkey 里补 `@connect`。

**Q：提示「令牌无效或缺失」？**
重新复制 `download-manager/config.json` 的 `server.access_token`；管理器里换过令牌就要重填一次。

**Q：油猴图标上不显示数字 / 菜单里找不到本脚本？**
当前域名不在 `@match` 白名单里（见上一节），或脚本被禁用了。

**Q：提交后任务立刻变成「失败」？**
去管理器看该任务的日志。两个常见原因：`javdock.com` 是滑动窗口式 HLS 防下载站
（本脚本在该域会提前给警示，下载器会拒绝执行）；YouTube 需要登录 cookie。

**Q：为什么没有页面上常驻的悬浮球？**
刻意的：用油猴**原生菜单**入口，不打扰正常浏览，也不需要往页面里塞常驻元素。

**Q：连续加好几个任务，会不会每加一个就打开一次管理器页面？**
不会。提交只调接口，不打开任何页面；要去看进度请点菜单里的「打开管理器页面」或结果条里的链接。

## 7. 已知边界

- **不提供 `sniff` / `play` 模式**：这两种要在桌面上手动点播放，从网页触发没有意义。
- **面板不显示进度**：只报「已加入任务 #id（排队中/运行中）」，进度去管理器页面看。
- **batch 在非内嵌站点仍会弹出有头浏览器窗口**，需要在桌面上看着它跑（内嵌站点不开浏览器）。
- 同类型任务同时只跑一个，第二个会**排队**（管理器既有行为）。

## 8. 自检

改过脚本后可以跑一次核心逻辑测试（不需要浏览器，也不需要管理器在运行）：

```powershell
node userscript/test_core.mjs
```

覆盖：域名 → 预选下载器/方式、集数/页码范围校验、以及 `buildTaskPayload()` 生成的请求体
键名是否与后端各适配器的 `form_schema` 一一对应（`ebook` 用 `book`、`ehentai` 用 `url`+`range`、
`video` 用 `mode`+`url`+…，这是最容易写错的地方）。
