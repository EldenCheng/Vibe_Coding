# e-download 使用指南

## 一、简介

e-download 是一个 E-Hentai 画廊图片下载工具。给定一个画廊链接,自动完成标题解析、页面列表获取、单线程限速下载、断点续传、失败重试与文件校验。

**核心特性:**

- 只下载网页显示的图片(非原图)
- 图片统一命名 `{页码:04d}_{网页显示名}`,顺序与网页一致
- 进度即时落盘(progress.json),中断后重新运行自动续传
- `--range` 指定下载范围,可分多次分段下载
- `--rd` 重试失败页、`--check` 校验实际文件(参考 fetech_xs 实现)
- 单线程 + 每页随机等待 3~5 秒,降低触发站点限流的风险
- 自动生成 `info.md` 画廊信息(Markdown 表格,标签双语显示)
- 目录名自动带分类/语言前缀与副标题,同类漫画排序聚合,方便查找
- 内容警告(Content Warning)画廊自动确认,无需人工干预
- 配置文件支持 proxy、延迟、重试、可选登录 Cookie、MPV 开关
- 图片下载"直连优先、代理回退"双通道,自动规避系统代理对图片节点的干扰

## 二、环境准备

### 2.1 安装 Python

确保系统已安装 Python 3.8+。验证方式:

```powershell
py --version
```

### 2.2 安装依赖

在 `e-download/` 目录下运行:

```powershell
py -m pip install -r requirements.txt
```

| 包名 | 用途 |
|------|------|
| requests | HTTP 请求与 Session 管理 |
| beautifulsoup4 | HTML 解析 |
| lxml | 解析引擎加速 |

## 三、快速开始

```powershell
cd e-download
py download_gallery.py "https://e-hentai.org/g/3743290/8eee725d8c/"
```

脚本会自动:
1. 解析画廊标题、总页数
2. 获取全部页面地址(优先 MPV API,失败自动回退缩略图解析)
3. 创建 `<画廊标题>/images/` 目录,逐页下载
4. 每页下载后立即写入 progress.json

## 四、命令行选项

```powershell
# 下载全部 / 断点续传
py download_gallery.py <画廊URL>

# 只下载指定页码范围
py download_gallery.py --range 1-10,20,30-40 <画廊URL>

# 重试失败页
py download_gallery.py --rd <画廊URL>

# 校验实际文件状态
py download_gallery.py --check <画廊URL>
```

### 4.1 下载范围(--range)

- 逗号分隔多个区间,`-` 表示连续范围,如 `--range 1-10,20,30-40`
- 页码从 1 开始;超出总页数的页码会被忽略并提示
- 可多次运行分段下载:先 `--range 1-40`,再 `--range 41-79`,已下载的页会自动跳过

### 4.2 重试失败页(--rd)

下载失败的页会记录在 progress.json 的 `failed` 列表中。运行:

```powershell
py download_gallery.py --rd <画廊URL>
```

只会重试 `failed` 中的页,可与 `--range` 组合限定重试范围。

### 4.3 校验实际文件(--check)

如果 progress.json 与 images/ 目录中的实际文件不一致(手动删除、崩溃等),运行:

```powershell
py download_gallery.py --check <画廊URL>
```

脚本会扫描 images/ 目录,按实际存在的文件重建 `downloaded` / `failed` 列表,缺失页自动加入 `failed`,之后可用 `--rd` 补下载。

## 五、断点续传

任何时候中断(按 Ctrl+C、关机),重新运行相同命令即可自动继续。原理:每页成功后立即写入 progress.json,下次启动跳过已下载页码。

## 六、画廊信息文件(info.md)

每次运行脚本都会刷新画廊目录下的 `info.md`,包含:

- **基本信息表**:副标题、分类、上传者、发布时间、语言、文件大小、页数、收藏、评分
- **标签表**:按分组排列(如 `female (女性)`),每个标签一行,格式 `英文 (中文)`
- **画廊链接**

标签翻译词典在 `tag_translations.py`,收录了约 800 条高频标签。**遇到没有翻译的标签**,编辑该文件的 `TAG_TRANSLATIONS` 字典自行添加即可(键为英文标签小写,值为中文)。

## 七、目录名规则

- 目录名格式:`[分类][语言]主标题[副标题]`
  - **分类**:网站 Category 原样英文,如 `Cosplay`、`Misc`、`Game CG`
  - **语言**:标签 `language` 分组中第一个实际语言值(小写,如 `chinese`),标签没写语言就不加
- 主标题长度 ≤ 40 字符且有副标题时追加副标题(副标题以 `[` 开头时用圆括号包裹)
- 总长度超过 100 字符时自动截断,保证 Windows 路径安全
- 非法字符(如 `:` `?` `*`)替换为空格
- **已下载的画廊**:若旧规则目录已存在(无前缀),自动沿用旧目录名,续传进度不丢

示例:

```
[Cosplay]The little Vampyr - Ekko
[Misc][chinese][ZONE] 校园奴隶契约 4
[Misc][chinese][禾樱] 十二品阶（上+下）
[C drive.] Chou Saiminjutsu Gakuen ([C drive.] 超催眠術学園)
```

## 八、配置文件说明

`config.json` 位于脚本同目录:

| 字段 | 说明 |
|------|------|
| `proxy` | 代理地址,如 `"http://127.0.0.1:7890"`,空字符串不使用显式代理(系统代理仍会生效) |
| `use_mpv` | 是否尝试 MPV API 获取页面列表(默认 `false`;游客访问 MPV 返回 "eeenope",关闭可省一次无效请求) |
| `request_delay.min/max` | 每页下载前的随机等待秒数(默认 3~5,**勿调太小**) |
| `retry.max_attempts` | 单页最大重试次数(默认 3) |
| `retry.backoff_base` | 首次重试等待秒数(默认 30,指数递增:30→60→120) |
| `timeout_page` | HTML 页面请求超时秒数(默认 30) |
| `timeout_image` | 图片请求超时秒数(默认 120,图片较大) |
| `headers` | 全局请求头 |
| `cookies` | 可选登录态 Cookie(ipb_member_id / ipb_pass_hash),公开画廊留空即可 |

## 八、进度文件说明(progress.json)

```json
{
    "gallery_url": "https://e-hentai.org/g/3743290/8eee725d8c/",
    "gid": "3743290",
    "token": "8eee725d8c",
    "title": "[Kyockcho] Lovely Aina-chan 1 + 2 + 3 [Decensored] [Digital]",
    "subtitle": "[きょくちょ] らぶりーあいなちゃん 1 + 2 + 3 [無修正] [DL版]",
    "total": 79,
    "downloaded": [1, 2, 3],
    "failed": [],
    "status": "complete"
}
```

| 字段 | 说明 |
|------|------|
| `downloaded` | 已成功下载的页码列表(1 起) |
| `failed` | 下载失败的页码列表 |
| `status` | `complete` / `in_progress` |

## 九、常见问题

### Q1: 需要代理吗?

e-hentai.org 在国内可能无法直连。若直连失败,在 config.json 中设置:

```json
"proxy": "http://127.0.0.1:7890"
```

端口请换成你本地代理软件的实际端口。

### Q2: 下载中途中断了怎么办?

直接重新运行相同命令,自动从上次中断处继续。

### Q3: 页面提示"限流警告"?

说明访问频率触发了站点临时限制,脚本会自动加长等待后重试。如果频繁出现,建议调大 `request_delay`。

### Q4: 需要登录吗?

公开画廊无需登录。MPV API 对游客不可用("eeenope"),脚本会自动回退缩略图解析,不影响下载。如需下载需要登录的画廊,把浏览器 Cookie 中的 `ipb_member_id`、`ipb_pass_hash` 填入 config.json 的 `cookies` 字段。

**注意:** 部分画廊对游客直接返回 404("Gallery Not Available"),但浏览器(已登录)可以正常打开——这是网站的"仅登录可见"机制,配置 Cookie 后即可下载。若脚本提示"画廊不可用(网站返回 404)",先检查浏览器是否已登录能打开。

### Q5: 如何删除进度重新下载?

删除对应画廊目录下的 `progress.json` 和 `images/` 文件夹,重新运行下载命令。

### Q6: 下载的图片是原图吗?

不是,是网页显示的图片(与浏览器里看到的一致)。如需原图,将来可扩展。

### Q7: 图片下载报"Connection aborted (10053)"?

这是系统代理(如 Clash)对 hath.network 图片节点(非标端口)主动断开连接导致的。脚本已内置双通道机制:图片优先**直连**(绕过系统代理),直连失败自动回退代理通道,一般无需手动处理。若仍大量失败,可检查代理软件是否对 `*.hath.network` 域名有特殊规则。

### Q8: 标签没有中文翻译?

编辑 `tag_translations.py` 中的 `TAG_TRANSLATIONS` 字典,按 `"english tag": "中文"` 格式自行添加即可,重新运行脚本会重新生成 info.md。

### Q9: 某些画廊需要"再次确认"才能看(Content Warning)?

脚本已自动处理:检测到内容警告页时自动访问 `?nw=session` 确认,该响应即真实画廊页并下发会话 Cookie,无需人工干预。

### Q10: MPV API 是什么?要开吗?

MPV 是 E-Hentai 的一个页面列表接口,游客/普通会员访问会得到 "eeenope"(需特殊权限)。默认关闭(`use_mpv: false`),脚本直接解析画廊缩略图获取页面列表;若你的账号有权限,可设为 `true` 尝试。
