# 版本变更 - e-download

## v1.2 (2026-08-30)

目录名增加分类/语言前缀 + 内容警告自动确认 + MPV 开关:

- 目录名格式升级为 `[分类][语言]主标题[副标题]`:
  - 分类 = 网站 Category 原样英文(如 `[Cosplay]The little Vampyr - Ekko`)
  - 语言 = 标签 `language` 分组中第一个实际语言值(如 `[Misc][chinese][ZONE] 校园奴隶契约 4`),标签未写语言时不加
- 旧规则目录(无前缀)已存在时自动沿用旧目录名,已下载画廊的续传进度不丢失
- Content Warning 画廊自动确认:检测到警告页时自动访问 `?nw=session`(响应即真实画廊页并下发会话 Cookie),不再报"页面列表获取失败"
- config.json 增加 `use_mpv` 开关(默认 false):游客访问 MPV 会返回 "eeenope",默认关闭跳过无效请求;开启后才会尝试 MPV API

## v1.1 (2026-08-29)

新增画廊信息保存与目录名优化:

- 画廊页信息完整抓取:副标题、分类、上传者、发布时间、语言、文件大小、页数、收藏、评分、标签分组
- 每次运行自动刷新 `info.md`:基本信息表 + 标签表(Markdown 表格,标签单元格内 `<br>` 每行一个,避免爆格)
- 标签双语显示:"english (中文)",英文为主、中文注释;新增 `tag_translations.py` 词典(分组前缀全量翻译 + 约 800 条高频标签,可自行增补)
- 目录名规则:主标题 ≤ 40 字符时追加副标题(格式 `主标题 [副标题]`,副标题以 `[` 开头时用圆括号避免嵌套),总长 ≤ 100 字符截断
- 文件名清洗优化:非法字符替换为空格(如 `[C:drive.]` → `[C drive.]`)而非直接删除
- progress.json 增加 `subtitle` 字段

修复图片下载被系统代理中断的问题:

- 现象:部分 hath.network 图片节点(非标端口)经系统代理(如 Clash)下载时报 10053 连接中止,而直连正常
- 原因:requests 默认读取 Windows 系统代理(注册表),curl/直连不受影响
- 方案:图片下载改为**双通道**——直连(绕过系统代理,单次短超时快速失败)优先,失败自动回退代理通道(完整重试)

## v1.0 (2026-08-23)

首个版本,实现 E-Hentai 画廊图片下载的全部核心功能:

- 支持输入画廊 URL(如 `https://e-hentai.org/g/3743290/8eee725d8c/`)自动解析 gid/token/标题/总页数
- 页面列表获取:优先 MPV API(`/mpv/{gid}/{token}/`),失败自动回退画廊页 `#gdt` 缩略图解析 + 翻页
- 只下载网页显示的图片(非原图),从查看页解析 `<img id="img" src>`
- 图片命名 `{页码:04d}_{网页显示名}`,保证排序与网页顺序一致
- 断点续传:progress.json 即时落盘,中断后重跑自动续传
- `--range 1-10,20,30-40` 指定下载范围(逗号分隔多个区间,可多次运行分段下载)
- `--rd` 重试失败页、`--check` 按实际文件校正进度(参考 fetech_xs 实现)
- 单线程下载,每页随机等待 3~5 秒(config 可调)
- 失败指数退避重试;检测到 IP 封禁提示自动加长等待
- config.json 支持 proxy、延迟、重试次数、超时、headers、可选登录 cookies
- 参考 design/e-hentail-downloader.js 油猴脚本的解析正则与下载机制
- 画廊返回 404 时给出友好提示：区分"已删除"与"仅登录用户可见（需在 config.json 配置 Cookie）"两种可能，不再笼统报网络错误
