# 版本变更

## v0.1.6 — 2026-09-04 — 截断限长+重试+提示（你截图 `While correct, the`）
- **现象**：`Vocabulary While correct, the` 句中断 + `Grammar/Relevance —`，`Raw` 显示 `vocabulary_reason` 截断，`MAX_TOKENS` 1200 对 12 字段中英 JSON 仍不足
- **修复**：
  - `src/ai/*Provider`：`max_tokens/maxOutputTokens 1200→1800`，`finishReason MAX_TOKENS/length` 自动重试 2200 + 精简提示 `Keep each reason under 20 words`
  - `src/scoring/parseEvaluation.ts`：Prompt 每维 reason 限 `≤20 英词/30 中文`，`strengths/weaknesses/suggestions` 各 1-2 句且总 JSON <300 词；解析新增 `wasTruncated` 检测（末尾非 `}`、悬空 `, ""`、任一维 null/短 reason <15 字即标 `truncated`），`repairTruncated` 已覆盖 `, ""`；新增 `truncated` 标记透传
  - `src/components/ResultPanel.tsx`：`truncated` 或任一分项 null 时顶部黄条提示 `⚠ 评价因模型输出过长被截断，已保留可用部分，请点重试评分获取完整版`，`Raw` 展开至 4096 并标 `…truncated for display`
- **验证**：`tsc -b` 0 errors, `vite build` success (225kB)

## v0.1.4 — 2026-09-04 — 截断修复 + 去发音 + 分维度归因 + 多题混合预留
- **问题1 已确认：截断 `Failed to parse JSON: { "vocabulary": 85, "pronunciation": 90, "grammar": 82, ""`**：`max_tokens 800→1200`（Gemini/Local），`parseEvaluation` 新增 `repairTruncated`（丢弃悬空 `, ""`/`, "`/`, ` 并闭合 `}` 的 4 路尝试 + 原 `+}`/`+"}` 兜底），已验证对 `..., "grammar":82, ""` 可修复
- **问题2 已确认：取消 pronunciation**：`EvaluationScores` 删 `pronunciation`（STT 文本无法真实评分且污染总分），`overall` 回退改为 3 维平均，Prompt 删发音维度，`ResultPanel` 删发音卡片、`allScores` 3 项
- **问题3 已确认：分维度扣分原因**：`EvaluationScores` 新增 6 字段 `vocabulary_reason/_zh`、`grammar_reason/_zh`、`relevance_reason/_zh`（<90 必引原文 `"..."`），`buildEvaluationPrompt` 要求每维 1 句 reason，`ResultPanel` 每维卡片下增 `ScoreReason`（英显+按钮切中文），`App.css` 新增 `score-item-head/reason-wrap` 样式
- **未来 3-5 题**：已确认采用 **C 混合**（顶部 1 份综合 + 下方 1-5 明细可展开），保留英显中切、综合沿用单题严格；本版已为 `reportBuilder` 预留结构（综合=本地 3 维平均 + LLM `generateReport`），下版 v0.2 将实现 `usePresetSession` 多题状态机与 `ReportScreen` 混合渲染
- **验证**：`tsc -b` 0 errors, `vite build` success (220kB)

## v0.1.5 — 2026-09-04 — 强制 JSON + Markdown 回退
- **问题**：`No JSON found in response: Strengths ZH:* 你的回答直奔主题... Weaknesses EN: First, the vocabulary choice of "bananas, apples and oranges"` — 模型无视 `ONLY JSON` 直接吐 markdown 标题

  - `src/scoring/parseEvaluation.ts`：Prompt 追加 `MUST output single JSON, no markdown headings, Start with { end with } + Example JSON`；新增 `parseMarkdownFallback`（抽 `Strengths/Weaknesses/Suggestions` 三段 + 正则抽 `vocabulary/grammar/relevance` 分数），`candidate===null` 时先走 markdown 回退再抛错，避免 `No JSON` 误报；分数抽不到时 `overall` 3 维平均回退，`raw` 仍保留
- **验证**：`tsc -b` 0 errors, `vite build` success (223kB)
