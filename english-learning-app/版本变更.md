# 版本变更

## v1.0.2 (2026-07-28)

### AI 模型升级与图片理解

**发布目标**：修复 Gemini API 404 错误，启用图片理解能力让评分更准确。

#### 变更

##### Gemini 模型升级
- **文件**: `demo/demo_config.json`
- **变更**: `textModel` 从 `gemini-1.5-flash` 升级为 `gemini-flash-latest`
- **原因**: `gemini-1.5-flash` 已被 Google 完全下线；`gemini-2.0-flash` 免费配额为 0；
  `gemini-flash-latest` 是稳定别名，始终指向最新 flash 模型，支持视觉理解，导致 API 返回 404

##### 图片理解能力
- **文件**: `demo/js/aiService.js`, `demo/js/app.js`
- **新增功能**:
  - 评分时将场景图片以 base64 格式发送给 Gemini（`gemini-2.0-flash` 支持视觉理解）
  - 图片作为 `inlineData` 与文字提示词一起发送，让 AI 能直接"看到"图片内容
  - 新增 `loadImageAsBase64(imagePath)` 方法加载图片
  - 图片加载失败时自动降级为纯文字描述评分
- **提示词优化**:
  - 明确告知 AI "已提供图片"，`imageDescription` 作为补充上下文保留
  - 相关性评分现在可以基于图片内容判断

#### 兼容性
- `gemini-flash-latest` 是 Google 的稳定别名，始终指向最新 flash 模型
- 支持 `generateContent` 方法，包含视觉理解能力
- 向后兼容：图片加载失败时仍能正常工作（降级为纯文字）

## v1.0.1 (2026-07-28)

### 缺陷修复版本

**发布目标**：修复Demo无法启动的问题，并修正若干与文档不一致的行为。

#### 修复

##### 服务器启动脚本无法运行
- **文件**: `demo/start_server.bat`
- **问题**:
  - 脚本通过`cd /d "%~dp0scripts"`切换到`demo\scripts\`，该目录不存在
    （`simple_server.py`实际位于项目根目录的`scripts\`下）
  - `simple_server.py`内部使用相对路径`demo`切换服务目录，必须从项目根目录运行
- **修复**:
  - 改为切换到项目根目录（`cd /d "%~dp0.."`）后调用`scripts\simple_server.py`
  - Python检测优先使用`py`启动器（本机约定），找不到时回退到`python`

##### 配置校验与文档不一致
- **文件**: `demo/js/config.js`
- **问题**: `validate()`将`gemini.apiKey`设为必填，缺失时应用启动即进入错误页；
  与项目实施文档"API Key为空时显示警告但不阻止启动"矛盾，
  且导致`app.js`中的`showConfigWarning()`成为死代码
- **修复**: 移除apiKey必填校验。apiKey缺失时欢迎页显示警告横幅，
  点击Start时才提示需要配置Key（与`app.js`既有逻辑吻合）

##### TTS可用性误判
- **文件**: `demo/js/ttsService.js`
- **问题**: `isAvailable()`要求`voices.length > 0`，而Firefox等浏览器的语音列表
  是异步加载的，导致初始化时TTS被误判为不可用并被永久禁用
- **修复**:
  - `isAvailable()`仅检查`speechSynthesis` API是否存在
  - `speak()`时若语音列表为空则先尝试重新获取，获取不到则使用默认语音

##### Windows下端口占用提示失效
- **文件**: `scripts/simple_server.py`
- **问题**: Windows下绑定被占用端口抛出的是`OSError`（WinError 10048）
  而非`PermissionError`，友好提示分支永远不会触发
- **修复**: 改为捕获`OSError`，统一给出"端口被占用，可用--port更换端口"的提示

#### 已知问题（本次未处理）
- AI响应解析失败时静默返回默认75分（文档标注为有意为之，后续版本考虑更明显的提示）
- 结果页HTML中存在写死的占位分数（显示前会被覆盖，无实际影响）
- `getImagePath()`写死`image.jpg`，暂不支持png

## v1.0.0 (2024-07-24)

### 初始版本 - Demo版本

**发布目标**：实现Chat With Me应用的基础功能演示，展示Mode 1（固定场景模式）的核心用户体验。

#### 新增功能

##### 场景数据生成系统
- **文件**: `scripts/generate_demo_scene.py`
- **功能**:
  - 从文本格式问题文件生成JSON场景数据
  - 自动解析questions.txt格式
  - 生成符合设计文档规范的场景结构
  - 支持图片资源复制和元数据生成
- **特性**:
  - 灵活配置场景ID和年级
  - 支持自定义标题和描述
  - 自动维护场景索引文件

##### Web服务器支持
- **文件**: `scripts/simple_server.py`, `demo/start_server.bat`
- **功能**:
  - 简单HTTP服务器避免file://协议限制
  - 支持CORS头便于开发调试
  - Windows一键启动脚本
  - 自动检测Python环境
- **特性**:
  - 可自定义端口和服务目录
  - 提供网络访问提示
  - 优雅的错误处理

##### 用户界面系统
- **文件**: `demo/index.html`, `demo/css/styles.css`
- **功能**:
  - 6个核心屏幕设计
  - 响应式布局设计
  - 现代化扁平化UI
  - 统一的设计系统
- **屏幕类型**:
  - Welcome Screen（欢迎界面）
  - Loading Screen（加载界面）
  - Question Screen（问题界面）
  - Evaluating Screen（评分界面）
  - Result Screen（结果界面）
  - Error Screen（错误界面）

##### JavaScript核心模块
- **文件**: `demo/js/*.js`
- **模块**:
  - `config.js`: 配置加载和验证
  - `sceneLoader.js`: 场景数据管理
  - `ttsService.js`: 文本转语音服务
  - `aiService.js`: AI评分服务
  - `uiController.js`: UI控制
  - `app.js`: 主应用逻辑

##### 配置管理系统
- **文件**: `demo/demo_config.json`
- **功能**:
  - AI服务配置（Gemini）
  - TTS功能配置
  - Demo设置
  - UI主题配置
- **特性**:
  - 支持TTS开关
  - API Key可配置
  - 主题颜色可自定义

#### 技术特性

##### 前端技术栈
- 纯HTML5 + CSS3 + Vanilla JavaScript
- 无需构建工具
- 无需外部框架依赖
- 浏览器原生API支持

##### AI集成
- Google Gemini API集成
- 四维度评分系统：
  - Vocabulary（词汇）
  - Grammar（语法）
  - Relevance（相关性）
  - Pronunciation（发音）
- 综合分数计算
- AI反馈生成

##### 语音功能
- Web Speech API集成
- 文本转语音（TTS）支持
- 可配置语音参数
- 中断和重播功能

##### 用户体验
- 流畅的屏幕切换动画
- 加载状态反馈
- 错误处理和恢复
- 无障碍设计支持

#### 文档系统
- **项目实施文档**: 详细的技术实现说明
- **场景生成器指南**: 工具使用教程
- **版本变更文档**: 版本历史记录

#### 已知限制
- 仅支持单一场景和单一问题
- 无数据持久化
- TTS在HTTP环境下可能不稳定
- 依赖网络连接和API可用性
- 需要手动配置API Key

#### 兼容性
- 浏览器支持：Chrome 120+、Edge 120+、Safari 16+
- Python要求：3.6+
- 推荐使用最新版本浏览器
