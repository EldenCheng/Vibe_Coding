# 问题分类提示词模板（grounded / open）

> 用途：新场景（新图 + 新题）入库前，用视觉大模型给每道题打题型标签，保证与现有 scene01/scene02 口径一致。
> 标签写进 `demo-app/public/scenes/<场景id>/questions.json` 每题的 `kind` 字段。
> 口径版本：v0.3.0（2026-09-17）。分类错标有兜底（见评分 prompt），但仍请尽量标对。

---

## 一、定义（先看这个）

- `grounded` = 看图锚定型：**标准答案基本能在图或 scoringDescription 里逐字定位**。学生只需观察、指认、复述、简单推理。
  - 典型动词：name / what can you see / what is he doing / what is the weather / retell with First..Finally / who is helping。
- `open` = 开放发挥型：**必须动用个人经验、观点、偏好、想象或扮演**，答案必然超出 description。评分时可能需要原图兜底判断。
  - 典型信号：you prefer / you usually / what gift will you bring / role-play / imagine you are / what do you like and dislike / where do you think they are going（预测去向）。

## 二、判定三问（按顺序，每题过一遍）

1. 离开图还能答吗？能 → 倾向 `open`；不能 → 倾向 `grounded`。
2. 题面是否要"为什么 / 更喜欢哪一个 / 你平时…"？是 → `open`（即使比较对象在图里）。
3. 是否扮演 / 预测 / 虚构对话？是 → 一律 `open`。

## 三、边界规则（易错点，直接照做）

1. "图里比 + 给理由"（如 scene01 l2q4 猜哪种水果最受欢迎 Why）：比较对象全在图里 → 标 `grounded`。
2. "Because 推理但锚定图"（如 scene02 l2q2 猜谁是 Yoyo）：证据在图里 → 标 `grounded`。
3. "复述排序"（First/Next/Then/Finally 描述 party 经过）：仍是图内事实 → `grounded`。
4. "人群往哪去 / 笑在聊啥"：超出画面 → `open`。
5. 凡 `Role-play / Imagine you are / If you are the owner` → 一律 `open`，不讨论。
6. 凡 `you usually / your birthday / what gift will you bring`（问学生自己生活）→ 一律 `open`。

## 四、发给大模型的模板正文（复制整段）

```
You are a question classifier for an English picture-speaking app for Chinese students.

Image: attached scene image.
Image description (scoringDescription): """{{SCORING_DESCRIPTION}}"""

Questions to classify (id + Level + text):
{{QUESTIONS_BLOCK}}

For example, format the block exactly as:
l1q1 (Level 1): Look at the picture. What fruits can you see? Name at least three.
l3q3 (Level 3): What are the good things and bad things about street markets? What do you like and dislike?

Definitions:
- grounded = the expected answer can be found almost word-for-word in the image/description (observe, name, retell, simple inference). Scoring needs description only.
- open = the student must use own experience, opinion, preference, imagination or role-play; the answer goes beyond the description. Scoring may need the original image.

Decision steps per question:
1. Can it be answered without the image? Yes -> lean open. No -> lean grounded.
2. Does it ask WHY / which do you prefer / what do you usually do? Yes -> open.
3. Is it role-play / prediction / invented dialogue? Yes -> always open.

Boundary rules (follow exactly):
- Compare-visible-items + Why (e.g. which fruit is most popular) -> grounded.
- Guess-with-Because grounded in visible evidence (e.g. who is Yoyo) -> grounded.
- Retell with First/Next/Then/Finally -> grounded.
- Predicting where people go / what laughing people talk about -> open.
- Any Role-play / Imagine you are / If you are the owner -> always open.
- Any question about the student's own life (you usually / your birthday / what gift will you bring) -> always open.

Output ONLY JSON, nothing else:
{"labels": [{"id": "l1q1", "kind": "grounded", "reason": "<=10 English words"}, ...]}
Kind must be exactly "grounded" or "open". Cover EVERY input question, same order.
```

### 占位说明

- `{{SCORING_DESCRIPTION}}`：填该场景 `meta.json` 的 `scoringDescription` 全文。
- `{{QUESTIONS_BLOCK}}`：按 `l{qid} (Level N): text` 逐行列出全部待分类题。
- 附件带上场景原图（`image.jfif`）。

## 五、贴回 App

1. 大模型返回示例：`{"labels": [{"id": "l1q1", "kind": "grounded", "reason": "names visible fruits"}, ...]}`。
2. 把每个 `kind` 回填到 `questions.json` 对应 id 的 `"kind"` 字段（只允许 `grounded`/`open`，缺省按 `grounded` 处理）。
3. 自检：`grounded` 题抽查 2 题，确认答案能在 `scoringDescription` 里找到依据；`open` 题抽查 2 题，确认离开图也能说出东西。
