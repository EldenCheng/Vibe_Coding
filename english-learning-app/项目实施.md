# Chat With Me Demo - 项目实施

## 项目概述

Chat With Me 是一个基于设计文档的Demo应用，旨在展示儿童英语学习应用的核心功能和用户体验。本Demo实现Mode 1（固定场景模式）的基本流程，让用户通过看图说话练习英语口语，并使用AI进行评分。

## 已实现功能

### 1. 场景数据生成系统

**文件位置**：`scripts/generate_demo_scene.py`

**设计思路**：
- 从文本格式的问题文件和图片资源生成符合设计文档规范的JSON格式场景数据
- 支持自动解析questions.txt中的问题
- 生成meta.json、questions.json和index.json
- 复制图片资源到目标目录

**实现方法**：
```python
class SceneGenerator:
    def __init__(self, source_dir, output_dir, scene_id, grade_level)
    def parse_questions(questions_file) -> List[Dict]
    def generate_meta_json(title, image_alt, image_description) -> Dict
    def generate_index_json(existing_scenes) -> Dict
    def copy_image(image_file, target_name) -> Path
    def generate_scene(questions_file, image_file, title, image_alt, image_description, overwrite)
```

**注意事项**：
- questions.txt格式必须严格遵循"第N个问题:"的格式
- 场景ID必须遵循`{gradeLevel}_{name}`的命名规则
- 脚本会自动创建必要的目录结构
- 默认覆盖现有场景，可通过overwrite参数控制

**使用方法**：
```bash
cd scripts
python generate_demo_scene.py
```

### 2. Demo配置系统

**文件位置**：`demo/demo_config.json`

**设计思路**：
- 集中管理应用配置，避免硬编码
- 支持TTS功能开关
- 支持主题自定义
- API Key需要用户手动配置

**配置结构**：
```json
{
  "aiProvider": "gemini",
  "gemini": {
    "baseUrl": "https://generativelanguage.googleapis.com",
    "apiKey": "",  // 用户需手动填写
    "textModel": "gemini-flash-latest"
  },
  "tts": {
    "enabled": true,
    "lang": "en-US",
    "voice": "Google US English",
    "rate": 0.9,
    "pitch": 1.0
  },
  "demoSettings": {
    "sceneId": "junior_market",
    "maxQuestions": 1
  }
}
```

**注意事项**：
- `gemini.apiKey`必须配置，否则Demo无法使用AI评分功能
- TTS在非localhost环境下可能不稳定
- `maxQuestions`控制Demo的问题数量，当前设置为1

#### 5.3 TTS服务模块
**文件位置**：`demo/js/ttsService.js`

**设计思路**：
- 封装浏览器原生SpeechSynthesis API
- 处理语音加载的异步性
- 支持中断和重播功能

**实现方法**：
```javascript
class TTSService {
    setConfig(config) -> boolean
    isAvailable() -> boolean
    speak(text, lang) -> Promise<void>
    stop() -> void
    interruptAndSpeak(text, lang) -> Promise<void>
}
```

**注意事项**：
- Firefox的语音列表是异步加载的，`isAvailable()`仅检查`speechSynthesis` API是否存在，
  不依赖语音列表是否加载完成，避免异步加载导致TTS被误判为不可用
- 朗读时若语音列表尚未加载会先尝试重新获取，获取不到则使用浏览器默认语音
- TTS在HTTP环境下可能不稳定
- 提供开启/关闭配置选项

#### 5.4 AI服务模块
**文件位置**：`demo/js/aiService.js`

**设计思路**：
- 实现Gemini API调用
- 构造评分提示词
- 解析AI响应并计算综合分数

**实现方法**：
```javascript
class AIService {
    setConfig(config) -> void
    async evaluateAnswer(params) -> Promise<Scores>
    buildEvaluationPrompt(question, answer, imageDescription, gradeLevel) -> string
    parseEvaluationResponse(data) -> Scores
    calculateCompositeScore(scores) -> number
}
```

**评分维度**：
- Vocabulary（词汇）：0-100分
- Grammar（语法）：0-100分  
- Relevance（相关性）：0-100分
- Pronunciation（发音）：0-100分

**综合分数计算**：
- 每个维度权重25%
- 四个维度分数加权平均后取整
- 结果钳制在[0, 100]范围内

**图片理解**：
- 评分时会将场景图片以 base64 格式发送给 Gemini（`gemini-flash-latest` 支持视觉理解）
- 图片作为 `inlineData` 与文字提示词一起发送，让 AI 能直接"看到"图片内容
- 若图片加载失败，自动降级为纯文字描述评分
- `imageDescription`（meta.json 中的图片描述）作为补充上下文保留在提示词中

**注意事项**：
- 提示词根据年级不同进行调整
- 失败时返回默认分数（75分）保证流程继续
- 支持JSON响应解析容错

### 6. Web服务器脚本

**文件位置**：`scripts/simple_server.py`

**设计思路**：
- 提供简单的HTTP服务器避免file://协议限制
- 支持CORS头便于开发调试
- 提供本地网络访问提示

**实现方法**：
```python
class CustomHTTPRequestHandler(SimpleHTTPRequestHandler):
    def end_headers(self) -> void  # 添加CORS头

def start_server(directory, port) -> void
def get_local_ip() -> string
```

**配置参数**：
- 默认端口：8000
- 服务目录：demo
- 支持命令行参数自定义

**注意事项**：
- 确保Python 3.6+已安装
- 端口被占用时会提示（Windows下端口占用抛出的是OSError，已统一捕获处理）
- 支持Ctrl+C优雅停止
- 必须从项目根目录运行（脚本内部通过相对路径`demo`切换服务目录）

### 7. 服务器启动脚本

**文件位置**：`demo/start_server.bat`

**设计思路**：
- Windows批处理脚本，方便一键启动
- 自动检测Python环境（优先使用`py`启动器，回退到`python`）
- 错误处理和用户友好提示

**实现方法**：
```batch
@echo off
REM Check Python installation (py preferred, fallback to python)
REM Navigate to project root (parent of demo directory)
REM Start server with error handling
```

**注意事项**：
- 需要Python在PATH中（`py`或`python`任一可用即可）
- 服务器崩溃时保持窗口打开显示错误
- 脚本自动切换到项目根目录（`%~dp0..`）再调用`scripts\simple_server.py`，
  因为服务器脚本内部使用相对路径`demo`作为服务目录，必须从项目根目录运行

## 已知限制

1. **TTS功能**：在HTTP环境下（非localhost）可能不稳定
2. **AI评分**：依赖网络连接和API可用性
3. **浏览器兼容性**：建议使用Chrome、Edge、Safari最新版本
4. **单场景限制**：Demo仅支持一个场景和一个问题
5. **无数据持久化**：所有会话数据不保存
