## 4. 配置大模型（必做）

Demo 支持 **两种** AI，二选一或都配（页面右上角可随时切换）：

### 4.1 Gemini 云端（推荐首选）

1. **获取免费 Key**：打开 https://aistudio.google.com/app/apikey → 登录 Google 账号 → Create API Key → 复制 `AIza...`。

2. **填入 Demo（二选一，A 更安全）：**

   **方式 A — 环境变量（推荐，不会提交到 git）：**
   ```powershell
   # PowerShell 临时生效（仅当前窗口）：
   $env:VITE_GEMINI_API_KEY="AIza...你的key..."

   # 验证是否生效：
   echo $env:VITE_GEMINI_API_KEY
   ```

   > 永久生效：`[System.Environment]::SetEnvironmentVariable("VITE_GEMINI_API_KEY","AIza...", "User")` 后重启 PowerShell。

   **方式 B — 直接写配置文件：**
   ```powershell
   notepad public\config.json
   # 把 "gemini": { "apiKey": "" } 改为 "apiKey": "AIza...你的key..."
   # 保存
   ```
   > 提示：代码优先读 `VITE_GEMINI_API_KEY`，再回落到 `config.json`。

3. **模型选择**（已在 `public/config.json` 配好，一般不需改）：
   ```json
   "gemini": {
     "textModel": "gemini-3.6-flash",
     "fallbackModel": "gemini-3.5-flash"
   }
   ```
   - `gemini-3.6-flash` 为当前对新用户可用的最新 Flash（2026-09-04 实测 `gemini-2.5-flash` 已 404：`is no longer available to new users. Please use models/gemini-3.6-flash`），失败自动切 `gemini-3.5-flash`。
   - 若你的项目仍提示 `model not found`，可尝试 `gemini-3.6-flash` / `gemini-3.5-flash` / `gemini-2.0-flash` 逐个试。

### 4.2 本地 Gemma4（可选，无需 Key，适合内网）

已在 `public/config.json` 预配：
```json
"local": {
  "baseURL": "/local-v1",
  "directBaseURL": "http://172.18.0.110:8080/v1",
  "apiKey": "EMPTY",
  "model": "gemma-4"
}
```
- `baseURL: /local-v1` 走 Vite 代理（解决 CORS），不要改成直连 IP，否则浏览器会拦截。
- `vite.config.ts` 已配：
  ```ts
  proxy: { '/local-v1': { target: 'http://172.18.0.110:8080', changeOrigin: true, rewrite: p=>p.replace(/^\/local-v1/,'/v1') } }
  ```
- 若你的 Gemma4 不在 `172.18.0.110`，同步改 `public/config.json` 的 `directBaseURL` 和 `vite.config.ts` 的 `target`。

> 本地模型速度较慢，评分需 30–40 秒属正常，Demo 已为 Local 单独设超时（`demo.localEvaluationTimeoutMs`，传图档 360s），超时可点"重试"。

### 4.3 火山方舟 GLM-5.3-Flash（可选，多模态）

已在 `public/config.json` 预配：
```json
"glm": {
  "baseURL": "/glm-v1",
  "directBaseURL": "https://ark.cn-beijing.volces.com/api/coding/v3",
  "apiKey": "",
  "model": "glm-5-3-flash-260828",
  "reasoningEffort": "low"
}
```
- **Key**（二选一，A 更安全）：环境变量 `VITE_GLM_API_KEY="你的Ark key"`（获取：火山引擎控制台 → 火山方舟 → API Key 管理），或填入 `glm.apiKey`。
- **模型 ID**：以控制台模型页（`name=glm-5-3-flash`）内示例代码为准——当前为 `glm-5-3-flash-260828`（带日期版本后缀，页面 slug 不带）；若报 `model not found`，对照控制台示例代码或改用 ep-xxx 接入点 ID。
- `baseURL: /glm-v1` 走 Vite 代理（解决浏览器直连 CORS），`vite.config.ts` 已配，不要直连 `ark.cn-beijing.volces.com`。
- `reasoningEffort` 为思考强度（`low/high/max`），评分任务建议 `low` 提速；若服务端拒绝该参数，代码会自动摘除重试。

### 4.4 评分模式：传图 vs 传描述（`demo.imageStrategy`，v0.2.3 起）

评分时给大模型"看图"的方式有两种，由 `public/config.json` 的 `demo.imageStrategy` 一个字段切换：

| 设置值 | 模式 | 评分模型看到什么 | 速度 | 前提条件 | 适合 |
|--------|------|------------------|------|----------|------|
| `"descriptionOnly"` **（当前默认）** | 描述档 | 只发文字描述 `scoringDescription`，**不发图** | 快（等待页提示 Gemini ~15-45s / GLM·Local ~60s 档） | 场景 `meta.json` 的 `scoringDescription` 要写得全 | 日常使用，快速出分 |
| `"image"` | 传图档 | 发压缩后的场景图（前端自动压到 1024px/0.72，无需手动处理） | 慢（Gemini/GLM 120s 档 / Local 最长 360s 档） | 无（模型直接看图，最保真） | 兜底验证、怀疑描述漏细节时 |

**怎么设置**：打开 `public/config.json`，找到 `"demo"` 节，改这一行后**保存并刷新浏览器页面**即可（`config.json` 是页面加载时读取的，不用重启 `npm run dev`）：
```json
"demo": {
  "imageStrategy": "descriptionOnly",
  ...
}
```

**对 app 的实际影响（只影响"评分"这一步，题目/朗读/录音不受影响）：**
- **描述档**：请求小、出分快；但评分模型**看不见图本身**，只看得见描述——描述里没写的细节，模型就不知道。例：图里有个机器人但 `scoringDescription` 没提，孩子答了"robot"可能被判"与图无关"。所以**每个新场景必须把 `scoringDescription` 写全**（生成方法见 §6「新增一个场景」与 `docs/生成评分描述提示词模板.md`）。
- **描述档下若某场景 `scoringDescription` 留空**：会自动改用较简短的 `imageDescription` 顶上，评分依据更少、判分更粗，不建议留空。
- **传图档**：模型直接看图，评分最保真；代价是请求大、等待久（Local 档最长 6 分钟）。`imageMaxSide: 1024` / `imageQuality: 0.72` 是传图档的压缩参数，一般不用动。
- **一句话建议**：日常保持 `descriptionOnly`；若某题评分明显"冤枉"孩子（答案明明在图里却判无关），先怀疑描述漏了细节 → 补 `scoringDescription`，或临时切 `"image"` 对比验证是不是描述的锅。

**怎么确认当前生效的是哪一档**：
- 最直观：看评分等待时长——描述档几十秒内出分，传图档明显更久（等待页的预计时长提示也不同）。
- 确凿法：浏览器按 F12 → Network → 找评分请求（GLM/Local 是 `chat/completions`，Gemini 是 `generateContent`）→ 看请求体：描述档**没有**图片 base64 字段，传图档有（`inlineData` / `image_url`）。

## 6. 在浏览器中使用 Demo

1. 打开 **Chrome/Edge** 访问 `http://localhost:5173/`（必须用 localhost，`127.0.0.1` 也可；不要用 `192.168.x.x`，否则麦克风被禁）。
2. 页面顶部看到 `Chat With Me — Demo`，右上角可切换 `AI: Gemini / GLM 5.3 Flash / Local Gemma4`。
3. **开始页（v0.3.0）**：先选学生年龄（`Ages 10-12 / 13-15 / 16-18`，影响评分严格度与 10-12 岁 TTS 降速），再选可出现的题型（`Picture-only` 只问图里的东西 / `Beyond-picture too` 也问想法经验），点 `Start`。选择会记住，下次默认上次的。场景仍自动加载（打开页面**随机**选一个；想固定用 `http://localhost:5173/?scene=scene02`）。图片加载后显示第 1 题（过滤后每级至多 1 题、有几题算几题：scene01 Picture-only 只有 2 题，问题卡带 `Level N` 徽章）并**自动朗读**；可点 `🔈 Read / 🔊 Stop` 重听。
4. 点 `🎤 点击录音 / Tap to record` → 对着麦克风说英语 → 再点 `⏹ 停止录音 / Stop`。
   - **停顿没关系（v0.2.7）**：说话中间想一会儿录音不会断；说话过程中文字会实时出现在答案框。
   - **接着说**：按停止后想补充，再点一次录音，新内容会**接在已录文本后面**；说砸了点 `🗑 清空重说 / Clear` 一键重来。
   - 成功：文字出现在 `Your answer` 文本框，可手动修改。
   - 失败提示 `Didn't catch that`：再试一次或直接打字。
   - 若顶部出现 `⚠️ Mic needs HTTPS/localhost`：说明你用了 `http://192.168...`，改用 `localhost`。
5. 点 `提交并评分 / Submit & Score` → **本图片不动，下半区刷新为本題得分**（v0.3.0 逐题即时评分）：分数头常显，点 `查看详细评价` 才展开亮点/失分项/改进建议。评分失败会停在原题，给 `重试评分 / 跳过本题`。
6. 点 `下一题 / Next` 切题（翻页动效，可在 `config.json: demo.questionTransition` 切 `fade/slide/flip/scatter/random/none`，默认 `flip`）；末题点 `查看汇总 / Summary` 进**汇总页**（本地聚合，零额外大模型调用）：
   - 顶部平均分 `/100` + 各题得分表
   - 低分/失败/跳过题进 `特别提醒 / Needs attention` 表格（评价与改进建议，弱项多时分页）
   - 点 `再来一次` 重新抽题（同一场景内排除本轮已出题目；刷新页面才会换随机场景），或 `返回开始页` 重选年龄/题型

### 新增一个场景（v0.2.6 起支持多场景）
1. 在 `public/scenes/` 下建 `sceneNN/` 目录，放三个文件：
   - `image.jfif` 场景图；`questions.json` 全量题库（每题 `id: "l{级}q{序}"` + `order` + `level` + `kind: grounded/open`，级数不限）；`meta.json`（`id/title/gradeLevel/audience/imageAlt/imageDescription/scoringDescription/createdAt`）
   - `kind` 题型打标规范见 `docs/问题分类提示词模板.md`（`grounded` 看图锚定只发描述 / `open` 开放发挥可发原图）；`audience` 字段保留但 v0.3.0 起评分受众改由开始页年龄决定
   - 两种描述：`imageDescription`（展示/识图降级，~100 词）与 `scoringDescription`（评分用单段 150-220 词，`descriptionOnly` 或 grounded 题替代发图）——生成方法见 `docs/生成评分描述提示词模板.md`
2. 在 `public/scenes/index.json` 的 `scenes` 数组中登记新 id。
3. 无需改代码。访问 `http://localhost:5173/?scene=sceneNN` 验证，或等随机抽到。

## 7. 局域网平板/手机访问（可选）

> 浏览器的 `SpeechRecognition` 在 **非安全上下文**（`http://192.168.x.x`）会被直接拒绝，必须 HTTPS。

### 仅本机测试（无需证书）
直接用 `http://localhost:5173`，最简单。

### 局域网 HTTPS（推荐一键脚本，v0.2.5 起）

**Windows 一键：**
```powershell
pwsh ./scripts/setup-https.ps1
# 自动完成：mkcert 安装/检查 → 安装本地 CA（UAC 确认）→ 选 IP → 签发 certs/localhost.pem
#          → 复制 rootCA.pem 到 certs/ → 读 .env.local 注入 key → npm run dev
# 常用参数：-NoStart 只生成不启动 / -IpAddress 192.168.1.100 跳过 IP 菜单
```
`vite.config.ts` 会自动探测 `certs/localhost.pem` 启用 https（无需改配置）；其他设备信任 `certs/rootCA.pem`（iOS 需在"证书信任设置"中开启）。详见 `局域网HTTPS证书分发详细教程.md`。

<details>
<summary>手动方式（备选，v0.2.4 及之前）</summary>

```powershell
# 1. 安装 mkcert（需先装 Chocolatey，或直接下载 mkcert.exe）
choco install mkcert

# 2. 安装本地 CA
mkcert -install

# 3. 生成证书（把 192.168.x.x 换成你的本机 IP，ipconfig 查看）
mkcert localhost 127.0.0.1 192.168.1.100

# 4. v0.2.5 起无需改 vite.config.ts（自动探测 certs/localhost.pem）；
#    旧版需取消注释 https 段指向 localhost+2.pem / localhost+2-key.pem

# 5. 重启
npm run dev -- --host 0.0.0.0
```
</details>

## 9. 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| `Configuration Error: gemini.apiKey is required` | 未填 Key 且 Provider=gemini | 按 §4.1 用环境变量或改 `public/config.json` |
| `Gemini error 404 / model not found` | 免费项目的可用模型不同；`2.0/2.5 Flash` 已于 2026 年对新用户停服（实测 404 提示用 `gemini-3.6-flash`） | 把 `public/config.json` 的 `textModel` 改为 `gemini-3.6-flash`，`fallbackModel` 为 `gemini-3.5-flash` |
| `GLM error 404 / model not found` | 模型 ID 与 Ark 控制台不符 | `glm.model` 改为控制台模型页示例代码中的 ID（当前 `glm-5-3-flash-260828`）或 ep-xxx 接入点；Key 检查 `VITE_GLM_API_KEY` |
| `CORS / Failed to fetch` 且切到 `local` | 直接请求 `172.18.0.110` 被拦截 | 保持 `baseURL: /local-v1`，走 Vite proxy；不要改成直连 |
| 点麦克风无反应 / `⚠️ Mic needs HTTPS` | 用了 `http://192.168.x.x` | 改用 `http://localhost:5173`，或按 §7 配 HTTPS |
| 说话停顿 ~1 秒录音就断 / 重录覆盖原文 | v0.2.6 及以前的旧行为 | 已在 v0.2.7 修复：停顿不断开、再录自动追加、附"清空重说"按钮。iPad Safari 表现略退化（只出最终文本），但停顿续录仍有效 |
| TTS 不响 | 浏览器未授权或 voice 未加载 | 检查是否点过页面任意位置（需用户交互）；刷新重试；Safari 需手动点 `Read` |
| 本地 Gemma4 评分很慢/超时 | 机器性能 | 正常，点"重试"或切回 Gemini/GLM；超时阈值在 `public/config.json` 的 `demo.localEvaluationTimeoutMs`（传图档 360s）可调 |
| 答案明明在图里，评分却说"与图无关" | 描述档下 `scoringDescription` 漏了该细节（模型看不到图） | 补全对应场景 `meta.json` 的 `scoringDescription`（方法见 §6/`docs/生成评分描述提示词模板.md`），或按 §4.4 临时切 `"imageStrategy": "image"` 直接传图对比 |
| `npm install` 很慢 | 网络 | `npm config set registry https://registry.npmmirror.com` |
