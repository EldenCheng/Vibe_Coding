# 项目设计文档 — english-learning-app (Chat With Me)

> 统一存放软件结构、编码过程等设计资料；设计变更时先更新本文档（AGENTS.md 要求）。

## 1. 项目概述
- **名称**：Chat With Me（儿童英语看图说话）
- **Demo 目标**：最小可跑闭环，验证浏览器端 TTS 读题 + STT 录音转文字 + 大模型识图评分链路。单固定场景 `Scene01`（集市）、全量 13 题三级题库（L1×3/L2×5/L3×5）中每级随机不重复抽 1 题（共 3 题），答完批量评分结算，展示分数与短评。
- **完整版愿景**见 `Design/design.md`：双模式（Mode1 固定场景/MODE2 AI动态）、Firebase、Profile、多场景。

## 2. Demo 范围界定（与完整版差异）
| 完整版 | Demo |
|---|---|
| 双模式入口 + FeatureFlags | 开始页（v0.3.4：单列居中—渐变背景 + 漂浮光斑 + 四角环境芯片 + 吉祥物 + Title/年龄分段/题型卡/渐变 CTA 四要素）→ 单场景会话 |
| 多场景 `public/scenes/*/index.json` | 单场景 `Demo/Scene01_image.jfif` 复制到 `demo-app/public/scenes/scene01/` |
| Firebase + Profile + History | 无，纯前端内存状态 |
| 3-5题连续 + 后台并发评分 | N 题会话（题型过滤后每级至多 1 题，有几题算几题）+ 逐题即时评分（v0.3.0，批量 Scoring 退为兼容保留） |
| 复杂路由 | 无路由，单 `App.tsx` 状态机 |

## 3. 技术选型
- **前端**：Vite 5 + React 18 + TypeScript 5（与 detailed-design 一致，复用后续代码）
- **语音**：Web Speech API — `SpeechSynthesis` (TTS) + `SpeechRecognition/webkitSpeechRecognition` (ASR)，`ttsService.ts` / `asrService.ts` 复用 §3G/3H 设计
- **AI**：Provider 抽象 `AIProviderInterface`；`GeminiProvider`（Google Generative AI SDK 兼容的 REST）+ `GLMProvider`（火山方舟 Ark OpenAI 兼容，GLM-5.3-Flash 原生多模态）+ `LocalProvider`（OpenAI Compatible `POST /v1/chat/completions` 指向 `http://172.18.0.110:8080/v1`）
- **样式**：原生 CSS + CSS Modules，无 Tailwind（保持 Demo 轻量，满足 WCAG AA 对比度、≥16px）
- **部署**：静态托管；HTTPS 要求见 §8

## 5. 核心流程（Demo 状态机）

### 5.1 单题流程（v0.1.x 已交付）
```
Idle -> ShowingQuestion (选题 + 自动TTS 300ms)
     -> Recording (ASR.start, 麦克风脉冲)
     -> ShowingTranscript (textarea 可编辑)
     -> Evaluating (fetch LLM, 15s超时, 显示 WaitingOverlay)
     -> ShowingResult (总分徽章 + 英文短评 + 中文翻译切换 + 四维展开)
```
- 选题：启动时从 Level1 3题 `Math.random` 选1，不持久化
- 自动朗读：挂载后 `setTimeout 300ms speak(question)`，允许 `interruptAndSpeak`
- 空转录：`onEmptyResult` → 软提示停留在 ShowingQuestion；技术错误 `onError` → 错误横幅

### 5.2 多题并发流程（v0.2.0，复刻 detailed-design.md §4B/4C）

**目标**：多场景下每级随机 1 题共 N 题（v0.2.6：scene01 为 3 题、scene02 为 4 题；v0.3.5 起 scene03 为 3 题；v0.3.7 起 scene04 为 4 题；各级随机抽 1 题、内存内不重复，题序按级升序），提交即后台评分，非最后一题等待无感。

**多场景支持（v0.2.6）**：
- 场景注册表 `public/scenes/index.json`（v0.3.6 起为对象列表）：`{"scenes": [{"id":"scene01","gradeLevel":"junior"}, …]}`（学段标注用于按年龄过滤；标题等详情仍在各场景 `meta.json`，不重复维护）
- 场景解析 `resolveSceneId(ageRange)`（`usePresetSession.ts`）：URL `?scene=scene02` 优先（经注册表白名单校验，非法值自动回退随机），否则在**与所选年龄同学段的场景**中**随机**选一个（映射：`10-12→primary / 13-15→junior / 16-18→senior`）；该学段无注册场景时**直接报错**进入 Error 屏（不跨学段回退，避免给高中生出小学题）；`restartSession`（再来一次）保持当前场景仅重抽题
- 场景数据三文件按 id 路径参数化加载：`/scenes/${id}/meta.json`、`questions.json`、`image.jfif`
- `meta.json` 新增 `audience` 字段（评分受众描述，见 §9.0）：scene01 = `Chinese junior students (13-15...)`、scene02 = `Chinese primary school students (10-12...)`、scene03 = `Chinese senior high school students (16-18...)`、scene04 = `Chinese primary school students (10-12...)`；加载后经 `SceneEvaluator.setAudience()` 注入批量评分
- 等配置就绪后再加载场景（避免配置到达前后二次随机换场景）

**Level 随机选题（v0.2.4）**：
- 题库：`questions.json` 全量题（scene01 13 题 `l1q1-l1q3 / l2q1-l2q5 / l3q1-l3q5`；scene02 16 题 `l1q1-l1q5 / l2q1-l2q3 / l3q1-l3q4 / l4q1-l4q4`；scene03 15 题 `l1q1-l1q4 / l2q1-l2q5 / l3q1-l3q6`；scene04 16 题 `l1q1-l1q4 / l2q1-l2q5 / l3q1-l3q4 / l4q1-l4q3`），每题带 `level` 字段；旧格式（无 `level`）兼容为顺序全用
- `pickQuestionsPerLevel(all, usedIds)`：按级分组 → 每级从未使用池随机抽 1 → 该级抽尽自动重置该级 → 按级升序排列为会话题序（级数由题库数据驱动，3 级/4 级均适配）
- 不重复范围（用户确认）：**仅内存**（`usedIdsRef`，本页生命周期内"再来一次"不重复，刷新清零）
- 评分 Prompt 标注每题 Level（L1 基础描述宽容 / L2 观察理解 / L3 开放表达重逻辑 / L4 角色扮演重得体与创造性）；`QuestionCard` 显示 `Level N` 徽章

```
Idle -> LoadingScene (fetch meta/qs + 图片转 base64 + 抽题)
     -> ShowingQuestion[0] (TTS L1 题)
     -> Recording -> ShowingTranscript -> Submitting(Q1) // fire-and-forget
                                └─> ShowingQuestion[1] (立即下一题，Q1 已在后台评)
     -> Recording -> ShowingTranscript -> Submitting(Q2) // 同上
                                └─> ShowingQuestion[2]
     -> Recording -> ShowingTranscript -> Submitting(Q3) --> ShowingResults
                                └─> await collectAllResults() (实际只等 Q3 尾延迟)
     -> ShowingReport (C1 折叠 + 本地综合，见 §9.1)
```

**并发评分（§4B SceneEvaluator）**：

```typescript
class SceneEvaluator {
  pendingEvaluations: Map<questionId, Promise<PresetEvaluationResult>>
  submitEvaluation(req: PresetEvaluationRequest): void // 立即 set(Map)，runWithTimeout
  collectAllResults(): Promise<PresetEvaluationResult[]> // Promise.all
  retrySingle(questionId, req): void // 覆盖 Map 中单项，单题重试
  reset(): void
}
// runWithTimeout: Promise.race([evaluate(), timeoutMs 后 resolve {timedOut:true, scores:null}])
// evaluate: buildEvaluationPrompt + provider.evaluate(with imageBase64) 主路径→纯文字降级
```

- 超时分档（v0.2.4）：传图档 `Gemini 120s（≥80s 兜底）/ GLM 120s（≥80s 兜底）/ Local 360s（≥120s 兜底）`，描述档 `Gemini 45s / GLM 60s / Local 60s`，外层/内层 -2s 差值；批量单次 `evaluateBatch` 1 次读图，`image` 模式自动 `canvas` 压缩到 `1024/0.72`
- 错误分类与退避保留：`errorKind`、`ReportScreen` 全量 `error`、`geminiProvider/glmProvider` 429/503 2s/4s 退避
- 重试语义（v0.2.2）：三合一后为 **整批重试**（`ReportScreen` 每题“整批重试”触发 `retryBatch`），不再单题重试
- 旧并发说明（v0.2.0/0.2.1 已废弃，保留参考）：曾为 3 路 `Map` 并发、每题 30s/40s，双 15s 同值竞速导致系统性超时
- 状态：沿用 `detailed-design.md §4C` 8 状态（`LoadingScene/ShowingQuestion/Recording/ShowingTranscript/Submitting/ShowingResults/ShowingReport/Error`），`Submitting` 非阻塞

**与单题差异**：`WaitingOverlay` 仅在 `ShowingResults` 短暂出现（`≈ max(Q3)` 而非 `sum(3)`），前两题无遮罩；`Transcribing` 灰态与 `retryPrompt` 保留

### 5.3 逐题即时评分 + 开始页 + 题型（v0.3.0）

**题型二分（内部标签 `grounded/open`，开始页英文展示）**：
- `grounded` = 看图锚定型：答案基本能在图/`scoringDescription` 里定位（如指认水果、天气、招牌、人物动作复述）；只发 description 即可准确评分。
- `open` = 开放发挥型：要观点/经验/扮演/预测，可能超出 description（如街市好坏、20 元买啥、role-play）；需要原图兜底判断。
- 落库：`questions.json` 每题 `kind` 字段；新题打标规范见 `demo-app/docs/问题分类提示词模板.md`（判定三问 + 边界规则）。
- 现有分类：scene01 grounded×7（l1q1-l1q3/l2q1-l2q4）+ open×6（l2q5/l3q1-l3q5）；scene02 grounded×8（l1q1-l1q5/l2q1-l2q3）+ open×8（l3q1-l3q4/l4q1-l4q4）；scene03 grounded×7（l1q1-l1q4/l2q1/l2q2/l2q4）+ open×8（l2q3/l2q5/l3q1-l3q6）。

**开始页（`StartScreen.tsx`，config 就绪后先渲染，不自动进题；v0.3.4 重设计：单列居中 + 只留四要素 + 动效可在系统关特效时存活）**：

> 用户确认的必备要素只有四个：Title `Chat With Me`、年龄选择、题型选择、开始按钮；其余一律为视觉装饰。

- 布局：`.start-screen`（圆角 28px + 分层 `radial-gradient`/`linear-gradient` 底）→ `.start-bg`（装饰层，`aria-hidden`）+ `.start-inner`（单列居中 flex column，`max-width 540px`，gap 26px）。
- 背景装饰：三个漂浮光斑（`blob-a/b/c`，`blobDrift`）+ 四枚环境芯片（`.float-chip` 👀🎤⭐💬，`chipFloat` + `--tilt` 自定义属性做倾斜）。**芯片放在面板四角留白带**（`chip-1..4` 分别 top-left / top-right / bottom-left / bottom-right），避免半隐在白色选项卡后面被误认为破图；窄屏（≤560px）隐藏下方两枚。
- Hero（`start-hero`）：内联 SVG 吉祥物（对话气泡 + 笑脸 + 挥手副气泡，`mascotBob` 浮动，`mascot-wrap` 为居中 flex column）+ 招呼气泡「Hi! 今天一起说英语 👋」（绝对定位在吉祥物右侧，窄屏降级为静态 inline 居中）+ 大 Title `Chat With Me!`（`clamp(40px,8vw,54px)` 蓝青渐变 `background-clip:text` + `titleShimmer` 缓慢流光）+ 中文副标题「看图聊英语 · 说出你看到的世界」。**已移除**：三步玩法 `Look / Say / Score` 卡行、场景预告走马灯（连带 `index.json`/`meta.json` 的预告 fetch 逻辑一起删）。
- 年龄（`.age-seg` 分段控件，`role=radiogroup`，组标题 `学生年龄 · Age`）：白底胶囊容器三列网格，每格 emoji（默认 13-15），选中项 `is-on` 渐变填充；`value` 与 `audienceForAge` 映射不变。≤380px 收紧内边距与字号防溢出。
- 题型（`.mode-row` 二选一卡，`role=radiogroup`，组标题 `题型 · Question types`）：`mode-emoji` + `mode-label`（14px 一行放下）+ 右上角 `mode-check` ✓ 徽章（`checkPop`）+ `mode-sub` 小字说明；窄屏（≤560px）改单列。
  - `Picture-only` — "Only things visible in the picture. Faster, no photo upload."
  - `Beyond-picture too` — "Also your ideas and experiences. Some questions upload the photo."
- 主 CTA `.start-cta` 渐变胶囊「开始对话 · Let's Go」+ 箭头（`ctaNudge` 轻推）：双层动画 `riseIn` 入场 + `ctaGlow` 呼吸光晕，`::after` sheen 扫光，悬停抬升。
- **动效降级策略（关键）**：Windows 关闭「显示动画效果」时浏览器上报 `prefers-reduced-motion: reduce`，v0.3.3 及之前用 `animation: none !important` 一刀切导致整页死静。新策略只停**位移类**动画（`mascot` / `float-chip` / `blob` / `start-cta-arrow`、CTA sheen、`ctaNudge`），入场降级为纯 `fadeIn`（保留错峰 delay），保留**透明度/颜色类**动效（`ctaGlow` 光晕、`titleShimmer` 流光），并关闭 transition。若要无视系统设置全量播放，删掉 `App.css` 中该 `@media (prefers-reduced-motion: reduce)` 块即可。
- 入场：`start-hero`、两个 `start-group`、CTA 依 `riseIn` 错峰（`.start-group:nth-of-type` 递增 delay）；保留 `radiogroup + aria-checked`。
- 选择记 `localStorage`（`el-start-age/el-start-filter`，下次默认上次的）；点 CTA 才 `loadScene()` 抽题。
- 过滤规则（用户确认"有几题算几题"，未变）：`Picture-only` 只留 `grounded`，`Beyond-picture too` 全留；`pickQuestionsPerLevel` 为"过滤池里每级至多 1 题、空级跳过"（如 scene01 / scene03 Picture-only 只有 L1+L2 共 2 题）。

**逐题流程（图片不刷新，同页出分）**：
```
Start -> LoadingScene (按题型过滤 + 每级至多1题 + 图片转base64)
     -> ShowingQuestion[i] (图片保持 imagePath 不变；TTS 读题，10-12 岁 0.85 速)
     -> Recording -> ShowingTranscript -> SubmittingSingle (下半区转圈，图片不动)
     -> ShowingSingleResult (同页：分数头 + 默认折叠的详细评价，点击展开)
        ├─ 失败 → 停在原题 [Retry scoring / Skip question]（用户确认方案）
        ├─ 非末题 → [Next question] 经 QuestionTransition 切题
        └─ 末题 → [View summary] -> ShowingSummary
```
- 单题 payload：`kind + ageRange` 参与 `shouldSendImage()` 与 prompt；`SceneEvaluator.evaluateSingle()`（外层单题超时：描述档 45-60s / 传图档 80-120s，内层 -2s）。
- 单题 prompt（`buildSingleEvaluationPrompt`）：受众由开始页年龄映射（不再用 `meta.audience`），加年龄校准段（10-12 重完整句+词汇准确；13-15 要细节+连接词；16-18 要逻辑+多样句式）与错标兜底（open 答得保守就图给分不罚没发挥；grounded 瞎发挥扣 relevance）。
- 汇总（`SummaryScreen.tsx`，零额外 LLM）：平均分 + 各题分表 + `Needs attention` 表格（overall<60 或跳过/失败题，列 weaknesses+suggestions），弱项多时分页（每页 2 条）。

**切题转场（`QuestionTransition.tsx`，纯 CSS）**：`config.demo.questionTransition ∈ {none,fade,slide,flip,scatter,random}`（默认 `flip`，用户确认），以 `currentIndex` 为 key 包 `QuestionCard+AnswerEditor` 区，350-500ms；`random` 每次随机抽一种（含 flip 在内、不含 none）。v0.3.1 起**不依赖系统减少动态效果设置**（用户确认：简单过渡即可，配置即所见；`none` 需手动配置）。

## 8. TTS / STT 详细
- **TTS** `WebSpeechTTSService`：`isAvailable() => 'speechSynthesis' in window`；`speak(text, lang)` 返回 Promise；`interruptAndSpeak` 先 `stop()` 再 `speak` 且抑制 `onStart`；`onStart/onEnd/onError` 回调驱动喇叭动画
- **ASR** `WebSpeechASRService`：`isAvailable() => (SpeechRecognition||webkitSpeechRecognition) && isSecureContext`；`startRecording(lang)/stopRecording()`；回调：`onResult`（录音中实时上屏）、`onSessionEnd({transcript, hasText})`（会话真正结束后触发，v0.2.7）、`onEmptyResult/onError`（保留兼容）；非安全上下文 `http://192.168.x.x` 直接提示需 https/localhost
- **ASR 连续录音（v0.2.7，用户实测反馈"停顿 ~1s 即断 + 重录覆盖"后重设计）**：
  - `continuous: true`（停顿=思考时间，Web Speech API 无静音容忍参数，此为唯一手段）+ `interimResults: true`（实时上屏，仅 `isFinal` 段落累计入文本）
  - **自动重启续录**：Chrome 的 continuous 会话仍会因长静音/网络抖动自发 `onend`——用户未按停止（`shouldListen` 意图标记）则 250ms 后自动重启，`finalBase` 已识别文本跨重启保留；连续失败 5 次才报错（成功识别即重置计数）；`not-allowed/service-not-allowed` 致命错误不重启
  - **追加语义（hook 层）**：`startRecording` 时快照文本框内容，显示 = 快照 + 会话累计（英文空格连接）；`AnswerEditor` 提供"清空重说"按钮一键重来
  - **状态机影响**：录音中 `onResult` 只更新文本**不切状态**（保持 `Recording`，实时流入）；`onSessionEnd` 接管切换（有文本 → `ShowingTranscript`；无文本且有旧文 → 直接回 `ShowingTranscript`；全空 → 重试提示）
  - **Safari/iPad 退化**：Safari 对 continuous/interim 支持不全（只出最终文本），自动重启机制仍生效，退化为"停顿后自动续录"
- **HTTPS 部署**：v0.2.5 起 `vite.config.ts` **自动探测** `certs/localhost.pem`（存在即 https，否则 http）；本机 `http://localhost:5173` 无需证书

### 9.0 评分 Prompt（单题）— v0.1.4 严格版（去发音+分维归因）
```

Image description: "<scene description>"
Question: "<question>"

- Tone: one sentence praise first, then direct improvements. No empty praise.
- Respond ONLY with JSON: {"vocabulary":int,"vocabulary_reason":"EN ... \"...\" if <90","vocabulary_reason_zh":"中文…\"...\"","grammar":int,"grammar_reason":"EN ...","grammar_reason_zh":"中文…","relevance":int,"relevance_reason":"EN ...","relevance_reason_zh":"中文…","overall":int,"comment":"1 sentence praise EN","comment_zh":"中文鼓励","strengths":"1 sentence EN - what was good","strengths_zh":"中文亮点","weaknesses":"2 sentences EN - specific errors causing point loss, quote \"...\"","weaknesses_zh":"中文逐条指错并引用原文","suggestions":"2 numbered tips EN, each with Example: \"...\"","suggestions_zh":"中文2条可执行技巧各带仿写句"}
```

## 14. 风险
- Gemini Key 配额/模型名变更 → 配置热切换 + 本地回退
- Gemma4 CORS → Vite proxy `/v1 -> http://172.18.0.110:8080`
- Ark GLM CORS/模型标识/端点变更 → Vite proxy `/glm-v1 -> https://ark.cn-beijing.volces.com/api/coding/v3`（token plan 专属端点，标准 API 为 `/api/v3`）；`config.glm.model` 可改（控制台模型 ID 或 ep-xxx）；`reasoning_effort` 被拒自动摘除重试
- STT 在 Firefox/HTTP 失效 → 降级手动输入
- 场景加载失败（`index.json` 或场景三文件缺失/损坏）→ 进入 Error 状态提示；`?scene=` 非法值自动回退随机场景，不影响可用性；所选年龄学段无注册场景（v0.3.6 按年龄过滤后）→ 报错提示换选年龄，不跨学段回退
- **API Key 前端持有（纯静态架构导致）**：`public/config.json` 为静态资源（`src/config/configLoader.ts:87 fetch('/config.json')`），Gemini 由浏览器直连（`src/ai/geminiProvider.ts:34`），`key` 必然前端可见。A档（家庭局域网）下通过“`config.json` 留空 + `VITE_GEMINI_API_KEY` 注入 + Key 配额/referrer 限制”缓解；公网场景需 B档后端代理（见 §15），本版不实现

## 15. 决策记录

- **2026-09-04 决策：方向1采用 A档（mkcert 局域网自签，零后端）**：由纯静态架构决定（`fetch('/config.json')` + 浏览器直连 Gemini），公网代理（B档：`浏览器→同源 /api/evaluate → Google`，key 仅存服务器）延后到 `v0.3`，本版仅在 `§8.1` 与详细教程中留设计位。
- **2026-09-15 决策（v0.2.4）**：
  - **Level 选题**：每级随机 1 题、会话共 3 题（L1→L2→L3 升序），"不重复"范围为**仅内存**（用户确认：页面刷新清零，某级抽尽自动重置该级），符合 demo 轻量定位；
  - **GLM 接入**：经官方文档评估，GLM-5.3-Flash 为原生多模态（GLM-5.3 非 Flash 为纯文本），可满足看图评分需要；接入走火山方舟 Ark OpenAI 兼容协议 + `/glm-v1` Vite 代理（规避 CORS，与 `/local-v1` 同模式），Key 经 `VITE_GLM_API_KEY` 注入；
  - **评分按级校准**：Prompt 标注每题 Level（L1 宽容/L2 观察/L3 重逻辑），用户确认采用。
- **2026-09-15 决策（v0.2.5，HTTPS 一键脚本）**：用户确认做局域网 HTTPS 一键脚本（而非历史记录/多场景）。实现采用"脚本只生成证书 + `vite.config.ts` 自动探测 `certs/localhost.pem`"方案，**替代**教程原"脚本改写 vite.config.ts 文本/手动取消注释"方案——改写文本脆弱且污染 git diff；证书固定名放 `certs/` 子目录并整体 gitignore。IP 变更重跑脚本覆盖证书即可，客户端 CA 无需重装。
- **2026-09-15 决策（v0.2.6，多场景）**：用户确认三点——① 场景切换用"**随机 + `?scene=` URL 参数覆盖**"（保持无开始页、打开即进入图+问题；老师可用带参数 URL 固定场景，非法值回退随机）；② **评分受众按场景注入**（scene01=13-15 junior 不变，scene02=10-12 primary 小学生；受众文案存 `meta.audience`，随场景注入评分 prompt，同时批量 prompt 题数硬编码 3 改为动态）；③ `useDemoSession.ts`（旧单题流程，无引用）**移入 `src/demo/deprecated/` 存档不删除**。场景 2 为 10-12 岁中国小学生设计的四格漫画「Yoyo's Birthday Party」（邀请卡/父母布置/中西餐宴席/桌游），16 题 4 级（新增 L4 角色扮演），`imageDescription`（展示）与 `scoringDescription`（评分）两种描述已按实测图片编写。
- **2026-09-15 决策（v0.2.7，STT 连续录音）**：用户实测反馈"学生想话时停顿 ~1s 录音即断，重录又覆盖原文，复杂题无法一气呵成"。根因：`continuous=false`（Web Speech API 无静音容忍参数）+ `onResult` 整体替换。用户确认两点：① 停止后再录音为**追加**并配"清空重说"按钮（否决"无按钮纯追加"与"保持覆盖"）；② 录音中**实时上屏**（否决"结束才出文本"）。实现采用 continuous + interim + 未停止自动重启续录；决策全文见 `讨论记录.md`。
- **2026-09-17 决策（v0.3.0，逐题评分 + 题型 + 开始页 + 转场）**：用户要求答完一题立即同页评分（图片不动、评价默认折叠）、三题合评改为逐题；题型二分（内部 `grounded/open`，开始页纯英文 option + 小字英文 label）；过滤"有几题算几题"；失败停在原题重试/跳过；汇总本地聚合零 LLM（含 Attention 表格分页）；转场 4 种 + random，默认 flip。决策全文见 `讨论记录.md`。
