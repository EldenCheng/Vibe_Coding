# 项目设计文档 — english-learning-app (Chat With Me)

> 统一存放软件结构、编码过程等设计资料；设计变更时先更新本文档（AGENTS.md 要求）。

## 1. 项目概述
- **名称**：Chat With Me（儿童英语看图说话）
- **Demo 目标**：最小可跑闭环，验证浏览器端 TTS 读题 + STT 录音转文字 + 大模型识图评分链路。单固定场景 `Scene01`（集市）、仅 Level1 3题中随机1题，答完即结算，展示分数与短评。
- **完整版愿景**见 `Design/design.md`：双模式（Mode1 固定场景/MODE2 AI动态）、Firebase、Profile、多场景。

## 2. Demo 范围界定（与完整版差异）
| 完整版 | Demo |
|---|---|
| 双模式入口 + FeatureFlags | 单页，无模式选择 |
| 多场景 `public/scenes/*/index.json` | 单场景 `Demo/Scene01_image.jfif` 复制到 `demo-app/public/scenes/scene01/` |
| Firebase + Profile + History | 无，纯前端内存状态 |
| 3-5题连续 + 后台并发评分 | 单题一次评分（仍保留超时） |
| 复杂路由 | 无路由，单 `App.tsx` 状态机 |

## 3. 技术选型
- **前端**：Vite 5 + React 18 + TypeScript 5（与 detailed-design 一致，复用后续代码）
- **语音**：Web Speech API — `SpeechSynthesis` (TTS) + `SpeechRecognition/webkitSpeechRecognition` (ASR)，`ttsService.ts` / `asrService.ts` 复用 §3G/3H 设计
- **AI**：Provider 抽象 `AIProviderInterface`；`GeminiProvider`（Google Generative AI SDK 兼容的 REST）+ `LocalProvider`（OpenAI Compatible `POST /v1/chat/completions` 指向 `http://172.18.0.110:8080/v1`）
- **样式**：原生 CSS + CSS Modules，无 Tailwind（保持 Demo 轻量，满足 WCAG AA 对比度、≥16px）
- **部署**：静态托管；HTTPS 要求见 §8

## 5. 核心流程（Demo 状态机）
```
Idle -> ShowingQuestion (选题 + 自动TTS 300ms)
     -> Recording (ASR.start, 麦克风脉冲)
     -> ShowingTranscript (textarea 可编辑)
     -> Evaluating (fetch LLM, 15s超时, 显示 WaitingOverlay)
     -> ShowingResult (总分徽章 + 英文短评 + 中文翻译切换 + 四维展开)
```
- 选题：启动时从 Level1 3题 `Math.random` 选1，不持久化
- 自动朗读：挂载后 `setTimeout 300ms speak(question)`，允许 `interruptAndSpeak`
- 空转录：`onEmptyResult` → 软提示停留在 ShowingQuestion；技术错误 `onError` → 错误横幅

## 6. 配置 `public/config.json`
```json
{
  "aiProvider": "gemini",
  "gemini": {
    "apiKey": "",
    "textModel": "gemini-3.6-flash",
    "fallbackModel": "gemini-3.5-flash"
  },
  "local": {
    "baseURL": "http://172.18.0.110:8080/v1",
    "apiKey": "EMPTY",
    "model": "gemma-4"
  },
  "tts": { "lang": "en-US", "voice": "", "rate": 0.9, "pitch": 1.0 },
  "asr": { "lang": "en-US" },
  "demo": {
    "evaluationTimeoutMs": 15000,
    "localEvaluationTimeoutMs": 40000
  }
}
```
- `gemini.apiKey` 优先读 `VITE_GEMINI_API_KEY` 环境变量，回落到 `config.json` 明文（家庭自用）
- `validateConfig` 检查：`aiProvider` 非空；若为 gemini 则 `apiKey` 非空；`tts.lang` 非空；`evaluationTimeoutMs` 正整数；`localEvaluationTimeoutMs` 若提供则必须为正整数
- 超时分档：`evaluationTimeoutMs` 供 Gemini（默认 15s），`localEvaluationTimeoutMs` 供 Local Gemma4（默认 40s，代码中 `Math.max(..., 40000)` 兜底，确保不少于 40s）
- 切换 Provider：页面右上角下拉即时生效，无需重启

## 7. 大模型选型（2026-09-03 调研，2026-09-04 更新）
- **Gemini**：1.5 Flash 已退役(2025-09-29)；2.0 Flash 于 2026-02-18 deprecated、2026-06-01 停服；2.5 Flash 于 2026-09-04 经实测对新用户已 404（`models/gemini-2.5-flash is no longer available to new users. Please use models/gemini-3.6-flash`），现主推 `gemini-3.6-flash`（报错原文指定）回落 `gemini-3.5-flash`。免费 Key 优先尝试 `gemini-3.6-flash`，失败回落到 `gemini-3.5-flash`。
- **本地 Gemma4**：OpenAI 兼容接口，无需 key，`model: gemma-4`，速度较慢需 **40s** 超时（`localEvaluationTimeoutMs: 40000`，代码兜底 `Math.max(...,40000)`）+ 重试
- **其他免费**：Groq/Vercel 上的 Gemini 同价需另 Key；纯免费 self-host 可选 `llava/qwen2-vl`（不在 Demo 范围）

## 8. TTS / STT 详细
- **TTS** `WebSpeechTTSService`：`isAvailable() => 'speechSynthesis' in window`；`speak(text, lang)` 返回 Promise；`interruptAndSpeak` 先 `stop()` 再 `speak` 且抑制 `onStart`；`onStart/onEnd/onError` 回调驱动喇叭动画
- **ASR** `WebSpeechASRService`：`isAvailable() => (SpeechRecognition||webkitSpeechRecognition) && isSecureContext`；`startRecording(lang)/stopRecording()`；`onResult/onEmptyResult/onError` 三回调互斥；非安全上下文 `http://192.168.x.x` 直接提示需 https/localhost
- **HTTPS 部署**：`vite --host 0.0.0.0` + mkcert 自签 `localhost+2.pem` 配置于 `vite.config.ts` 注释；本机 `http://localhost:5173` 无需证书

## 9. 评分 Prompt（单题）— v0.1.4 严格版（去发音+分维归因）
```
You are a STRICT but supportive English teacher for Chinese junior students (13-15, average level).
Image description: "<scene description>"
Question: "<question>"
Student answer: "<transcript>"
Grade strictly on 0-100: vocabulary, grammar, relevance. Also overall 0-100. No pronunciation. Be honest - high scores must still have deductions. Even overall 88 must have at least two distinct issues in different dimensions.
Rules:
- For EACH of vocabulary, grammar, relevance: give int score AND one-sentence reason. If score < 90, reason MUST quote a short fragment from the student's answer with "..." that caused deduction.
- Overall 88 must list at least two distinct issues (different dimensions) and two actionable suggestions, each with ONE corrected example sentence the student can imitate.
- Tone: one sentence praise first, then direct improvements. No empty praise.
- Respond ONLY with JSON: {"vocabulary":int,"vocabulary_reason":"EN ... \"...\" if <90","vocabulary_reason_zh":"中文…\"...\"","grammar":int,"grammar_reason":"EN ...","grammar_reason_zh":"中文…","relevance":int,"relevance_reason":"EN ...","relevance_reason_zh":"中文…","overall":int,"comment":"1 sentence praise EN","comment_zh":"中文鼓励","strengths":"1 sentence EN - what was good","strengths_zh":"中文亮点","weaknesses":"2 sentences EN - specific errors causing point loss, quote \"...\"","weaknesses_zh":"中文逐条指错并引用原文","suggestions":"2 numbered tips EN, each with Example: \"...\"","suggestions_zh":"中文2条可执行技巧各带仿写句"}
No explanation outside JSON.
```
- 发送：主路径 `parts: [inlineData(imageBase64), text(prompt)]`；失败降级为纯文字
- 解析：`extractBalancedJson` + 贪婪 + 去 fence/`<think>`、去尾逗号、**增量修复截断** `, ""`/`,"`/`","` 悬空（`repairTruncated` 4 路尝试），截断如 `...,"grammar":82, ""` 可自动丢弃尾悬空键后闭合；`max_tokens 1200` 避免再截断；`overall` 缺失时由 **3 维**平均回退；`vocabulary/grammar/relevance_reason` 缺省兼容为空

## 10. 等待体验
- **遮罩**：半透明 + 转圈 + 文案轮播每2s（"老师正在听..." / "正在分析发音..." / "马上就好..."）；Gemini 显示 `Usually 5–15s`，Local 显示 `Usually 30–40s`
- **小游戏**：Canvas 水果掉落（与集市场景呼应：苹果/橙子/香蕉/火龙果），点击 +1 分本地计数，不影响评分；`requestAnimationFrame`，评分 `Promise.race` 完成后自动关闭
- **超时**：Gemini 15s / Local 40s 未回 → 显示“有点慢，重试或继续等待”
