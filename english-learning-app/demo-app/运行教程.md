## 1. 环境要求

| 工具 | 最低版本 | 检查命令 | 说明 |
|------|----------|----------|------|
| Node.js | 18+ | `node --version` | 推荐 20 LTS；本机已验证 v26.3.1 |
| npm | 9+ | `npm --version` | 随 Node 安装 |
| 浏览器 | Chrome 120+ / Edge 120+ / Safari 16+ | — | Firefox 的 STT 需手动开 flag，不推荐 |
| Python | 无需 | — | Demo 是前端项目，不需要 Python |

**检查：**
```powershell
node --version   # 例如 v20.11.0
npm --version    # 例如 10.2.3
```
若未安装，去 https://nodejs.org 下载 LTS 版，安装后重启 PowerShell 再检查。

## 3. 安装依赖

```powershell
cd english-learning-app\demo-app
npm install
```
- 首次约 30–60 秒，生成 `node_modules/`。
- 若公司内网卡住，可切换镜像：`npm config set registry https://registry.npmmirror.com` 后重试。

**验证安装：**
```powershell
npm run build
# 期望：✓ built in ...ms  无报错
```

## 4. 配置大模型（必做）

Demo 支持 **两种** AI，二选一或都配（页面右上角可随时切换）：

### 4.1 Gemini 云端（推荐首选）

1. **获取免费 Key**：打开 https://aistudio.google.com/app/apikey → 登录 Google 账号 → Create API Key → 复制 `AIza...`。

2. **填入 Demo（二选一，A 更安全）：**

   **方式 A — 环境变量（推荐，不会提交到 git）：**
   ```powershell
   # PowerShell 临时生效（仅当前窗口）：
   $env:VITE_GEMINI_API_KEY="AIza...你的key..."

   # 验证是否生效：
   echo $env:VITE_GEMINI_API_KEY
   ```

   > 永久生效：`[System.Environment]::SetEnvironmentVariable("VITE_GEMINI_API_KEY","AIza...", "User")` 后重启 PowerShell。

   **方式 B — 直接写配置文件：**
   ```powershell
   notepad public\config.json
   # 把 "gemini": { "apiKey": "" } 改为 "apiKey": "AIza...你的key..."
   # 保存
   ```
   > 提示：代码优先读 `VITE_GEMINI_API_KEY`，再回落到 `config.json`。

3. **模型选择**（已在 `public/config.json` 配好，一般不需改）：
   ```json
   "gemini": {
     "textModel": "gemini-3.6-flash",
     "fallbackModel": "gemini-3.5-flash"
   }
   ```
   - `gemini-3.6-flash` 为当前对新用户可用的最新 Flash（2026-09-04 实测 `gemini-2.5-flash` 已 404：`is no longer available to new users. Please use models/gemini-3.6-flash`），失败自动切 `gemini-3.5-flash`。
   - 若你的项目仍提示 `model not found`，可尝试 `gemini-3.6-flash` / `gemini-3.5-flash` / `gemini-2.0-flash` 逐个试。

### 4.2 本地 Gemma4（可选，无需 Key，适合内网）

已在 `public/config.json` 预配：
```json
"local": {
  "baseURL": "/local-v1",
  "directBaseURL": "http://172.18.0.110:8080/v1",
  "apiKey": "EMPTY",
  "model": "gemma-4"
}
```
- `baseURL: /local-v1` 走 Vite 代理（解决 CORS），不要改成直连 IP，否则浏览器会拦截。
- `vite.config.ts` 已配：
  ```ts
  proxy: { '/local-v1': { target: 'http://172.18.0.110:8080', changeOrigin: true, rewrite: p=>p.replace(/^\/local-v1/,'/v1') } }
  ```
- 若你的 Gemma4 不在 `172.18.0.110`，同步改 `public/config.json` 的 `directBaseURL` 和 `vite.config.ts` 的 `target`。

> 本地模型速度较慢，评分需 30–40 秒属正常，Demo 已为 Local 单独设 40 秒超时（`demo.localEvaluationTimeoutMs: 40000`，代码兜底不少于 40s），超时可点“重试”。

## 5. 启动开发服务器

```powershell
# 确保在 english-learning-app/demo-app 目录
# 若用方式 A 的环境变量，需在同一窗口执行：
$env:VITE_GEMINI_API_KEY="AIza...你的key..."  # 若已用方式 B 可跳过
npm run dev
```

**期望输出：**
```
VITE v8.x.x  ready in ...ms
➜  Local:   http://localhost:5173/
➜  Network: http://192.168.x.x:5173/
```

- 不要关闭此窗口；按 `Ctrl+C` 停止。
- 端口被占用：`npm run dev -- --port 5174`。

## 6. 在浏览器中使用 Demo

1. 打开 **Chrome/Edge** 访问 `http://localhost:5173/`（必须用 localhost，`127.0.0.1` 也可；不要用 `192.168.x.x`，否则麦克风被禁）。
2. 页面顶部看到 `Chat With Me — Demo`，右上角可切换 `AI: Gemini / Local Gemma4`。
3. 场景图片自动加载，下方随机 1 题（Level1 三题之一）并**自动朗读**；可点 `🔈 Read / 🔊 Stop` 重听。
4. 点 `🎤 点击录音 / Tap to record` → 对着麦克风说英语 → 再点 `⏹ 停止录音 / Stop`。
   - 成功：文字出现在 `Your answer` 文本框，可手动修改。
   - 失败提示 `Didn't catch that`：再试一次或直接打字。
   - 若顶部出现 `⚠️ Mic needs HTTPS/localhost`：说明你用了 `http://192.168...`，改用 `localhost`。
5. 点 `提交并评分 / Submit & Score` → 全屏等待遮罩 + 转圈 + 水果掉落小游戏（点水果加分，纯娱乐，不计入评分）。
6. 5–15 秒后显示结果页：
   - 顶部大字 `总分 /100`（≥80 绿 / ≥60 黄 / <60 红）
   - 四维：词汇/语法/相关度/发音（某维失败显示 —）
   - `老师点评 / Feedback`：英文 + 按钮切换中文翻译
   - 点 `再试一题 / Another question` 随机换题；点 `重试评分 / Retry` 重新请求。

## 7. 局域网平板/手机访问（可选）

> 浏览器的 `SpeechRecognition` 在 **非安全上下文**（`http://192.168.x.x`）会被直接拒绝，必须 HTTPS。

### 仅本机测试（无需证书）
直接用 `http://localhost:5173`，最简单。

### 局域网 HTTPS（推荐 mkcert 自签）

**Windows 步骤：**
```powershell
# 1. 安装 mkcert（需先装 Chocolatey，或直接下载 mkcert.exe）
choco install mkcert

# 2. 安装本地 CA
mkcert -install

# 3. 生成证书（把 192.168.x.x 换成你的本机 IP，ipconfig 查看）
mkcert localhost 127.0.0.1 192.168.1.100

# 4. 修改 vite.config.ts，取消注释 https 段：
# https: { cert: fs.readFileSync('./localhost+2.pem'), key: fs.readFileSync('./localhost+2-key.pem') },

# 5. 重启
npm run dev -- --host 0.0.0.0
```
其他设备：把 `mkcert -CAROOT` 目录下的 `rootCA.pem` 传到平板/手机并手动信任（iOS 需在“证书信任设置”中开启）。

## 9. 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| `Configuration Error: gemini.apiKey is required` | 未填 Key 且 Provider=gemini | 按 §4.1 用环境变量或改 `public/config.json` |
| `Gemini error 404 / model not found` | 免费项目的可用模型不同；`2.0/2.5 Flash` 已于 2026 年对新用户停服（实测 404 提示用 `gemini-3.6-flash`） | 把 `public/config.json` 的 `textModel` 改为 `gemini-3.6-flash`，`fallbackModel` 为 `gemini-3.5-flash` |
| `CORS / Failed to fetch` 且切到 `local` | 直接请求 `172.18.0.110` 被拦截 | 保持 `baseURL: /local-v1`，走 Vite proxy；不要改成直连 |
| 点麦克风无反应 / `⚠️ Mic needs HTTPS` | 用了 `http://192.168.x.x` | 改用 `http://localhost:5173`，或按 §7 配 HTTPS |
| TTS 不响 | 浏览器未授权或 voice 未加载 | 检查是否点过页面任意位置（需用户交互）；刷新重试；Safari 需手动点 `Read` |
| 本地 Gemma4 评分很慢/超时 | 机器性能 | 正常，点“重试”或切回 Gemini；超时阈值在 `public/config.json` 的 `demo.localEvaluationTimeoutMs`（默认 40000，至少 40s）可调大到 60000 |
| `npm install` 很慢 | 网络 | `npm config set registry https://registry.npmmirror.com` |
