## 2026-09-17 · v0.3.2 启动页活泼化

- **背景**：启动页太工程素（学生教学用太平淡）；选项大卡片怪；年龄小字说明多余；配色与问题页不一致。
- **讨论过的方案**：AI 给出 Hero 三选一（卡通渐变/场景图预览/极简标题）、选项三选一（小胶囊/紧凑列表/缩小卡片）、Logo 三选一（emoji/简单SVG/暂不做）、额外想法多选（三步玩法/题数预告/鼓励语/都不加）。
- **用户决策**：
  1. Hero 用卡通渐变（渐变横幅+大Title+副标题，与问题页蓝系一致）。
  2. 选项用小胶囊 pills（年龄只给选项不给说明；小字说明只在题型下保留）。
  3. Logo 用简单 SVG 定制（对话气泡+笑脸，零外部资源）。
  4. 额外只加三步玩法说明（Look/Say/Score），题数预告与鼓励语暂不做。
- **理由**：学生端要活泼但不能增依赖增体积；配色复用问题页 tokens 最省且统一；年龄小字对选型无帮助只留题型处；三步玩法让学生一眼懂流程。

## 2026-09-17 · v0.3.0 逐题即时评分 + 题型 + 开始页 + 切题转场

- **背景**：三题合评要等末题才出分；部分题答案固定、部分题要自由发挥，统一传图又慢又贵；无开始页、无年龄区分、无切题动效。
- **讨论过的方案**：AI 提议内部标签 `grounded/open`（standard/advance 易误解为难度），开始页英文 option + 小字说明；过滤空级两种处理（跨级补足 vs 有几题算几题）；失败两种处理（停原题重试/跳过 vs 放行后补评）；转场 fade/slide/flip/scatter + random + none。
- **用户决策**：
  1. 命名用纯英文 option（内部 `grounded/open`），下方小字英文解释区别（Picture-only / Beyond-picture too）。
  2. 初分类暂定（scene01 grounded×7 + open×6；scene02 grounded×8 + open×8），判定标准沉淀为 `docs/问题分类提示词模板.md` 供新场景复用。
  3. 汇总要轻量本地聚合（零额外 LLM），低分/失败题进 `Needs attention` 表格列评价与建议，多则分页。
  4. `imageStrategy` 三档键名可用（`descriptionOnly / imageForOpenOnly / imageAll`，旧 `image` 映射 `imageAll`）；过滤"有几题算几题"；失败停原题重试/跳过；转场默认 `flip`。
- **理由**：同页出分减少等待焦虑；题型分流省时间省 token；英文 option 让学生/家长直选；本地汇总零成本且弱项表格可直接用于复习。

## 2026-09-15 · v0.2.7 STT 连续录音（停顿不断开 + 追加续录）

- **背景（用户实测反馈）**：学生回答复杂问题（L2-L4 长答案）时说话中间要想一会儿，但 STT 停顿 ~1 秒就自动结束录音；再次点录音，新识别结果**直接覆盖**已录文本。简单题尚可一气呵成，复杂题几乎无法完成。
- **根因**：`asrService.ts` 写死 `continuous=false`（Web Speech API 无静音容忍参数可调），且 `onResult` 每次整体替换文本框。
- **讨论过的方案**：AI 提议"continuous + 实时上屏 + 未停止时自动重启续录"，就两个体验点征求意见。
- **用户决策**：
  1. 按停止后再录音 → **追加**（英文空格连接）+ 提供"🗑 清空重说"按钮（不选"无按钮纯追加"：孩子说砸了需要一键重来；不选"保持覆盖"：正是要修的痛点）
  2. 录音过程**实时上屏**（不选"结束才出文本"：孩子有"被听到"的确定感）
- **附带说明**：Safari/iPad 对 continuous/interim 支持不全（只出最终文本），但自动重启机制同样生效，退化为"停顿后自动续录"；自动重启连续失败 5 次才真正报错（有成功识别即重置计数），避免死循环。

## 2026-09-15 · v0.2.6 多场景支持（三项决策）

- **背景**：用户备好场景 2（四格漫画「Yoyo's Birthday Party」，为中国 10-12 岁小学生设计）；要求做多场景支持 + 准备场景 2 两种 description。用户明确：场景太少，**暂不做开始页/年级选择**，保持打开即进入图+问题。
- **用户决策**（三选一问答）：
  1. 场景切换 = **随机 + `?scene=` URL 参数覆盖**（老师可用带参 URL 固定场景；非法值回退随机）——不选"仅 URL"（孩子重玩没变化）、不选"纯随机"（老师无法固定场景）
  2. 评分受众**按场景注入**：`meta.audience` 字段进评分 prompt（scene01=13-15 junior、scene02=10-12 primary），同时批量 prompt 硬编码"3 题"改动态——不选"只修题数"：用 13-15 标准评 10-12 岁会偏严
  3. `useDemoSession.ts`（旧单题流程，无引用）**建废弃目录移入存档**，不删除——用户原话"能否建个废弃目录, 把脚本放到这个目录里先"（AI 原提议是删除，被否）
- **补充**：题目 txt 中 YoYo/YOYO 拼写不一，统一为 Yoyo（AI 主动微调，已告知）。

## 2026-09-15 · v0.2.5 方向选择与 HTTPS 脚本方案

- **背景**：候选方向三个（历史记录 / 多场景 / HTTPS 一键脚本），用户选先做 **HTTPS 一键脚本**（为平板试用铺路）。
