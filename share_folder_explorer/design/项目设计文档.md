# 项目设计文档 - Share Folder Explorer

## 1. 项目概述
本项目旨在通过 Web 浏览器方便地访问 Windows SMB 共享文件夹，支持移动端浏览器访问。

## 2. 核心功能
- 使用前端与后端结构
- 弹窗输入用户名（不含域名）与密码
- 后端使用 **smbprotocol**（smbclient）纯协议库通过 SMB 协议访问共享文件夹
- 自动补全域名（通过 config.json 配置）
- 提供文件管理器功能：浏览、进入目录、新建目录、上传、下载、删除
- 支持 24 小时内同设备自动登录（Session 持久化）
- 支持切换用户
- 后端定时清理过期凭据与 Session

## 3. 技术选型
- **后端**: Python + Flask
- **SMB 协议**: `smbprotocol`（通过 `smbclient` API 实现文件操作，纯 Python 实现，不依赖操作系统 SMB 客户端）
- **数据库**: SQLite (存储加密凭据与 Session)
- **前端**: HTML + CSS + Vanilla JavaScript (使用 XOR 对传输数据进行加密)
- **加密**: 
    - 传输加密: XOR + 一次性密钥（每次登录前端获取新密钥，加密后发送，服务端解密）
    - 存储加密: Fernet 持久化密钥

## 4. 项目结构
```
share_folder_explorer/
├── config.json                  # 共享路径、端口、session超时等配置
├── index.html                   # 前端单页面（含CSS/JS）
├── start.bat                    # Windows 批处理启动脚本
├── requirements.txt             # Python 依赖：flask, smbprotocol, cryptography
├── scripts/
│   ├── __init__.py              # 使 scripts 成为 Python 包
│   ├── server.py                # Flask 主入口，路由注册，启动后台清理线程
│   ├── smb_handler.py           # SMB 文件操作封装（基于 smbprotocol.smbclient）
│   ├── auth_manager.py          # 认证、session 管理、SMB session 注册与切换
│   ├── crypto_utils.py          # 加密工具（Fernet 持久化密钥 + XOR 传输加密）
│   └── db.py                    # SQLite 数据库操作
├── data/                        # 运行时生成：SQLite 数据库 + Fernet 密钥文件
└── design/
    ├── 提示词.txt
    ├── 项目设计文档.md
    └── 版本变更.md
```

## 5. 数据库设计

### credentials 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增ID |
| username | TEXT | 用户名 |
| encrypted_password | TEXT | Fernet 加密后的密码 |
| created_at | TIMESTAMP | 创建时间 |

### sessions 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增ID |
| token | TEXT UNIQUE | UUID4 随机令牌 |
| credential_id | INTEGER FK | 关联 credentials.id |
| user_agent | TEXT | 设备标识 |
| created_at | TIMESTAMP | 创建时间 |
| last_active | TIMESTAMP | 最后活跃时间 |

## 6. API 设计
- `GET /api/auth/key`: 获取一次性 XOR 传输密钥
- `POST /api/auth/login`: 登录
- `POST /api/auth/logout`: 登出
- `GET /api/auth/session`: 验证 session
- `GET /api/auth/switch`: 切换用户
- `GET /api/files/list?path=`: 列出目录
- `POST /api/files/mkdir`: 新建目录
- `POST /api/files/upload`: 上传文件
- `GET /api/files/download?path=`: 下载文件
- `POST /api/files/delete`: 删除文件/目录

## 7. 设计思路与安全性
- **传输安全**: 通过一次性 XOR 密钥加密用户名密码，防止明文传输。
- **存储安全**: 凭据使用 Fernet 算法加密存储，密钥文件独立存放。
- **Session 管理**: 使用 UUID4 作为 Token，并在数据库中记录最后活跃时间，由后台线程定时清理。
- **域名管理**: 登录时自动使用 `config.json` 中的域名补全用户名，实现用户无感登录。
- **SMB 访问**: 使用 **smbprotocol** 纯协议库，通过 `smbclient` API 进行文件操作。
  - **连接管理**：使用 `smbclient.register_session()` 注册 SMB 凭据，`smbclient.delete_session()` 注销。
  - **多用户切换**：同一服务器同时只能有一套活跃凭据，通过 `delete_session` + `register_session` 切换不同用户的认证凭据。
  - **并发控制**：`AuthManager` 内使用 `threading.Lock` 保护 session 切换操作，确保同一时间只有一个用户的请求在处理 SMB 连接切换。
  - **连接清理**：用户登出或 session 过期时，通过 `delete_session` 清理已注册的凭据。
  - 不依赖操作系统 SMB 客户端（无 net use / cmdkey），避免 Windows 的 SMB 冲突限制。
  - 不占用盘符，无用户数上限。
  - 文件 I/O（scandir、makedirs、open_file、remove、rmdir）均通过 smbclient 在 Python 空间完成。

## 8. 从零搭建环境指南

### 8.1 前置条件

- **操作系统**: Windows 10 / 11
- **Python**: 3.13+（如果使用其他版本，需自行测试兼容性）
- **网络**: 运行本机器的电脑需要通过 TCP 445 端口能访问到目标 SMB 服务器
- **SMB 服务器**: 确保目标共享路径存在且你有权访问

### 8.2 获取项目代码

将 `share_folder_explorer` 整个目录复制到目标机器的任意位置（例如 `D:\Tools\share_folder_explorer`）。

### 8.3 安装 Python 依赖

```cmd
cd D:\Tools\share_folder_explorer
py -m pip install -r requirements.txt
```

如果遇到网络问题无法从 `pypi.org` 下载包，请检查是否为公司的代理网络，必要时配置 `pip` 代理：

```cmd
py -m pip install -r requirements.txt --proxy http://your-proxy:port
```

`requirements.txt` 中的依赖：

| 包名 | 用途 |
|------|------|
| flask | Web 框架 |
| smbprotocol | SMB 纯协议实现 |
| cryptography | Fernet 存储加密 |

### 8.4 修改配置

编辑 `config.json`：

```json
{
    "share_path": "\\\\192.168.8.199\\upload",
    "domain": "wesoft.com",
    "server": {
        "host": "0.0.0.0",
        "port": 80
    },
    "session": {
        "max_age_hours": 24,
        "cleanup_interval_minutes": 60
    }
}
```

| 配置项 | 说明 |
|--------|------|
| `share_path` | 目标共享文件夹的 UNC 路径 |
| `domain` | 登录时自动补全的域名（不设则留空） |
| `server.host` | 监听地址。`0.0.0.0` 表示监听本机所有 IP |
| `server.port` | 监听端口。可选 80（需管理员权限）或 9000（无需权限） |
| `session.max_age_hours` | Session 有效期，超过此时间未活跃自动登出 |
| `session.cleanup_interval_minutes` | 后台清理过期 session 的时间间隔 |

### 8.5 启动服务

双击 `start.bat`，或在命令行中执行：

```cmd
cd D:\Tools\share_folder_explorer
py -m scripts.server
```

看到以下输出则表示启动成功：

```
Starting server on 0.0.0.0:80
 * Running on http://127.0.0.1:80
 * Running on http://192.168.19.191:80
```

### 8.6 从浏览器访问

**同机访问**: `http://127.0.0.1`（或对应端口）

**手机 / 其他设备访问**:
1. 查看运行服务器的电脑 IP（`ipconfig` 命令获取，如 `192.168.19.191`）
2. 在手机浏览器中打开 `http://192.168.19.191`（或对应端口）
3. 输入 SMB 共享的用户名（不含域名）和密码，点击登录
4. 登录成功后即可浏览、上传、下载文件

如果端口为 80，访问时只需输入 IP 即可（浏览器默认端口为 80）。其他端口需要手动指定，如 `http://192.168.19.191:9000`。

### 8.7 防火墙与网络检查

如果启动后其他设备无法访问，请检查：

```
# 在运行服务器的电脑上测试端口是否开放
Test-NetConnection -ComputerName localhost -Port 80

# 从其他设备上测试能否连上
Test-NetConnection -ComputerName 192.168.19.191 -Port 80
```

如果 `TcpTestSucceeded : False`，可能是 Windows 防火墙阻止了端口。需要放行端口（以 80 端口为例）：

```cmd
# 以管理员身份运行
netsh advfirewall firewall add rule name="Share Folder Explorer" dir=in action=allow protocol=TCP localport=80
```

### 8.8 常见问题

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 登录失败：Authentication failed | 用户名或密码错误 | 确认在 login.microsoft.com 上可以登录 |
| 登录失败：SMB connection failed | 无法连接 SMB 服务器 | `Test-NetConnection 目标IP -Port 445` 确认网络连通性 |
| 启动报错 ModuleNotFoundError | 未安装依赖 | 检查是否执行了 `pip install -r requirements.txt` |
| 其他设备无法访问网页 | 防火墙阻止端口 | 按 8.7 节放行端口 |
| 上传文件失败 | 共享目录权限不足 | 确认 SMB 用户对该目录有写入权限 |
