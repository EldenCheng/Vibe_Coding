# 版本变更

## [v3.2.0] - 2026-07-15
- 修复下载/删除 access denied 问题
  - 根本原因：smbprotocol 连接有生命周期，服务器侧断开后 `_active_credential_id` 仍是旧值，导致 `get_smb_handler` 跳过重新注册，所有后续操作报 STATUS_LOGON_FAILURE
  - 修复方案：`get_smb_handler` 加入探活逻辑（`smbclient.stat`），连接失效时自动重新 `register_session`
- 抑制 smbprotocol 正常断开时的 `socket aborted by peer (WSAESHUTDOWN)` 日志噪音


- 全面重写 index.html，适配手机端与桌面端
  - 手机：卡片式列表，大触摸目标，底部固定工具栏，safe-area 支持，原生 `100dvh`
  - 桌面（≥768px）：切换为表格视图，显示大小/日期独立列，更紧凑的操作按钮
  - 文件图标按类型自动匹配（图片/视频/音乐/压缩包/代码等）
  - 目录优先排序，同类型按名称字母序
  - 用自定义 Dialog 替换 alert/prompt/confirm（对手机更友好）
  - Toast 通知替代弹窗报错
  - Loading overlay 防重复操作
  - 支持多文件批量上传
  - 面包屑自动滚动到当前目录


- 彻底重写 SMB 层，抛弃 net use，改用 smbprotocol 纯协议实现
  - 新依赖：smbprotocol（替代 pysmb，更新 requirements.txt）
  - smb_handler.py：全部文件操作改用 smbclient API（scandir/makedirs/open_file/remove/rmdir）
  - auth_manager.py：连接管理改用 smbclient.register_session / delete_session
  - 不再依赖操作系统 Session，无 net use 路径解析 bug，无 error 1219
  - 天然支持多用户，切换用户通过 delete_session + register_session 重建

## [v2.2.0] - 2026-07-15
- 修复登录后立即弹出 "Failed to load files" 的 bug
  - 根本原因：`net use` 之前只挂载 `IPC$`，仅建立身份认证通道，文件 I/O 走的 `\\server\share` 从未被挂载，Windows 使用进程默认凭据访问失败
  - 修复方案：`_switch_connection` 改为对 `\\server\share`（实际共享路径）执行 `net use`，确保文件 I/O 走正确的认证凭据
  - `_disconnect` 同步更新，断开时同时清理 `\\server\share` 和 `IPC$` 两条连接

## [v2.1.0] - 2026-07-15
- 连接管理从 SMBHandler 提升到 AuthManager 层级
  - 登录时通过 IPC$ 建立持久 SMB 连接
  - 文件操作复用已有连接，不再每次 mount/unmount
  - 切换用户时才重建连接，彻底解决 error 1219
- 前端错误提示改为显示后端实际 error 信息，方便调试
- 修复 UNC 路径解析 bug（lstrip 替换 replace+split）
- 移除 smb_port 配置项

- 支持在 config.json 中配置默认域名
