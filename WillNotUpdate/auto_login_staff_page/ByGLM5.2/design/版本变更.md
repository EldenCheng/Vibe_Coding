# 版本变更 — 员工通知网页自动登录助手

## v0.1.0 (2026-07-20)

初始版本。

### 新增

- 油猴用户脚本 `auto_login_notice.user.js`
- 工作日（周一至周五）9:00 自动打开 `网址` 并填入凭据登录
- 严格错过不补：9:00 时若无 http 页面常驻则当天不触发
- 当天只触发一次：通过 `GM_setValue('lastTriggerDate', today)` 去重
- 已有目标标签时自刷新：通过 `triggerEpoch` / `claimedEpoch` 认领机制协调，避免重复新开标签
- 登录框选择器：`#loginUsername` / `#loginPassword` / `#loginScreen .login-box button`（id 级，基于 page_source.txt 第 1035-1041 行）
- 已登录跳过：若 reload 后 `#loginScreen` 已 hidden（app.js 自动恢复会话），不重复填表
- 带重试的 DOM 等待：`fillLogin()` 失败时 500ms 重试，最多 10 次
- 油猴菜单命令：
  - `⏰ 设置触发时间` — 修改触发时间并重置今日触发状态
  - `🧪 立即测试触发` — 绕过周末/时间检查立即触发
  - `🔄 重置今日触发状态` — 清除 `lastTriggerDate` 让真实触发重新生效
- 凭据写死在脚本顶部 `CONFIG` 对象（占位符 `YOUR_USERNAME` / `YOUR_PASSWORD`，安装前填入）

### 文档

- `项目设计文档.md` 新增「8.2 脚本注入时机（重要）」章节，说明油猴脚本在页面加载时注入、安装后需对已打开的标签页 F5 刷新一次、菜单命令的显示位置（在 Tampermonkey 弹出菜单顶部而非脚本分组下方）

### 已知限制

- 仅跳过周末，不判定法定节假日和调休补班
- 9:00 时浏览器必须至少有一个已注入脚本的 http 页面常驻（安装前已打开的页面需 F5 刷新一次才注入）
- 凭据明文存储在脚本源码中
- 无法枚举/控制其他标签，依赖 epoch 认领机制间接协调
