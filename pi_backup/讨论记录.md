# 讨论记录 —— pi 数据备份工具

> 记录时间：2026-09-19
> 记录范围：本次对话（pi 数据备份工具从需求提出到完成实现）

---

## 一、需求提出（用户的想法）

用户正在使用 pi agent，已在 pi 上建立了一些用户设置并运行了一些 session，希望有一个 Python 脚本用于备份这些数据，以便出问题时可以恢复。具体要求：

1. 新建一个项目文件夹，建立备份 Python 脚本；
2. 运行脚本后，自动在项目文件夹的 `backup` 目录下建立一个当前日期的目录，把要备份的文件存放到该目录下，并**压缩**以减少空间占用；
3. 生成一份"脚本备份与手工恢复"的帮助文件；
4. 生成讨论记录，记录本次对话的想法、回应、问题与答案。

## 二、我的调查与回应

收到需求后，我先做了两项调查：

1. **查阅 pi 文档**（`environment-variables.md`）：确认 pi 的配置目录默认为 `~/.pi/agent`，可用环境变量 `PI_CODING_AGENT_DIR` 覆盖；
2. **检查本机实际数据**（`C:\Users\Elden\.pi\agent\`，共约 5.5MB）：

| 内容 | 大小 | 说明 |
|------|------|------|
| `settings.json` | ~1K | 用户设置 |
| `auth.json` / `auth.json.bak` | ~1K | API 密钥（敏感） |
| `models.json` / `models-store.json` | ~4K | 模型配置 |
| `sessions/` | ~1.6M | 会话历史（3 个 jsonl） |
| `bin/fd.exe` | ~4.0M | 下载的工具二进制 |

**我的回应**：向用户报告了数据存储位置与内容清单，并指出 `bin/fd.exe` 占 4MB、可被 pi 重新获取，若排除可大幅减小备份体积；同时提醒 `auth.json` 含明文 API 密钥，备份需妥善保管。

## 三、我的问题与用户的答案

| # | 我的问题 | 用户的答案 | 后续影响 |
|---|----------|------------|----------|
| 1 | `bin/fd.exe`（4MB 工具二进制）是否纳入备份？建议排除 | **排除** | 脚本中 `EXCLUDE_PATTERNS = ["bin"]`，备份体积减少约 70% |
| 2 | 压缩格式选 zip 还是 tar.gz？ | **zip**（Windows 双击即可打开） | 脚本使用 `zipfile` + `ZIP_DEFLATED` |
| 3 | 是否自动清理旧备份？ | **不清理**，备份以日期文件夹为单位，备份多时手工删除旧文件夹 | 脚本不做清理逻辑，日期目录累积 |
| 4 | 项目文件夹名？ | **`pi_backup`**（可以） | 项目创建于 `pi_backup/` |

## 四、实现过程

1. 创建项目目录 `pi_backup/`；
2. 按项目规范先写《项目设计文档.md》（数据源分析、模块划分、设计决策、恢复方案）；
3. 编写备份脚本 `backup_pi.py`（函数级模块化，含中文注释）；
4. **实测运行**：

   ```
   待备份文件数：8
   原始 1606.5 KB → 压缩后 519.8 KB（节约 67.6%）
   ```

   验证 zip 内 8 个文件路径正确、`bin/` 已排除、清单文件正常生成；
5. 补充《备份与恢复帮助.md》《版本变更.md》及本文档。
