# pi 数据备份与恢复帮助

本工具用于备份 pi coding agent 的用户设置与会话数据，出问题时可按本文档手工恢复。

- 备份工具：`backup_pi.py`
- 备份内容：pi 数据目录（默认 `C:\Users\<用户名>\.pi\agent\`）下的设置、认证信息、模型配置与会话历史
- 排除内容：`bin\` 目录（pi 自动下载的工具，可重新获取，不备份以减小体积）

---

## 一、如何备份

### 步骤

1. 打开命令提示符（cmd）或 PowerShell；
2. 进入本项目目录：

   ```bat
   cd /d H:\Sharing\Vibe_Coding\Vibe_Coding\pi_backup
   ```

3. 运行脚本：

   ```bat
   py backup_pi.py
   ```

4. 看到 `备份完成 ✔` 即表示成功，备份存放在：

   ```
   backup\<当前日期>\pi_agent_备份_<日期>.zip
   backup\<当前日期>\备份清单.txt
   ```

### 备份产物说明

| 文件 | 说明 |
|------|------|
| `pi_agent_备份_<日期>.zip` | 压缩备份包，zip 内路径与 pi 数据目录结构一致 |
| `备份清单.txt` | 备份时间、文件清单、压缩率等，用于核对备份完整性 |

### 补充说明

- **同一天重复运行**：不会覆盖旧压缩包，新包文件名会追加时间（如 `pi_agent_备份_2026-09-19_15-30-05.zip`）。
- **多天备份**：每个日期一个文件夹，累积保存。备份太多时，直接删除 `backup\` 下旧的日期文件夹即可。
- **自定义数据目录**：如果 pi 数据不在默认位置，可先设置环境变量再运行：

  ```bat
  set PI_CODING_AGENT_DIR=D:\你的路径\.pi\agent
  py backup_pi.py
  ```

- **依赖**：仅使用 Python 标准库，无需 pip 安装任何包。

## 二、如何手工恢复

> ⚠️ 恢复会**覆盖**当前 pi 的数据，请务必先按下面"第 0 步"备份当前状态，避免操作失误。

### 第 0 步（强烈建议）：备份当前 pi 数据

万一恢复失败或操作失误，先把当前数据挪到旁边留底：

```bat
ren %USERPROFILE%\.pi\agent agent_出事前的备份
```

（如提示被占用，先关闭所有 pi / cmd / PowerShell 窗口再试。）

### 第 1 步：关闭所有 pi

关闭所有正在运行的 pi 窗口，避免文件被占用导致恢复失败或数据冲突。

### 第 2 步：找到要恢复的备份

在 `backup\` 下找到目标日期文件夹，例如：

```
H:\Sharing\Vibe_Coding\Vibe_Coding\pi_backup\backup\2026-09-19\
```

用 `备份清单.txt` 确认该备份包含你需要的会话与设置。

### 第 3 步：解压备份包

右键 `pi_agent_备份_<日期>.zip` → **全部解压缩**，解压到一个临时目录（例如桌面 `pi_restore`）。解压后应看到：

```
pi_restore\
├── auth.json
├── auth.json.bak
├── models-store.json
├── models.json
├── settings.json
└── sessions\...（会话文件）
```

### 第 4 步：复制回 pi 数据目录

将解压出的**所有内容**复制到 pi 数据目录，覆盖同名文件：

```bat
xcopy /E /Y pi_restore %USERPROFILE%\.pi\agent
```

（把 `pi_restore` 换成你实际解压的目录。）

> 若第 0 步重命名过 `agent` 目录，请先执行：
> ```bat
> mkdir %USERPROFILE%\.pi\agent
> ```
> 再执行上面的 xcopy。

### 第 5 步：验证恢复

1. 打开 pi，确认：
   - 主题、默认模型等设置与备份时一致；
   - 历史会话仍能查看/继续（`sessions\` 下的会话）。
2. 确认无误后，可删除第 0 步的留底目录 `agent_出事前的备份`；
3. 确认有问题，可把留底目录改回 `agent` 以回退。

---

## 三、注意事项

1. **敏感信息**：压缩包内含 `auth.json`（明文 API 密钥）。备份目录请妥善保管，**不要**外传或上传到公开仓库。
2. **`bin\` 目录不备份**：恢复后 pi 在需要时会自动重新下载 `fd.exe`，无需手动处理。
3. **恢复期间不要运行 pi**：务必先关闭所有 pi 再恢复，否则文件被占用会失败。
4. **版本兼容**：建议使用与备份时相同或更新版本的 pi 恢复；若 pi 升级后数据结构变化，旧备份内容可能无法完全兼容（届时以最新一次备份为准）。
