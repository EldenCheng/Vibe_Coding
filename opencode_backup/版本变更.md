# 版本变更记录

## v0.1.0 (2026-09-15)

初始版本。

- 建立 opencode 数据备份脚本 `backup_opencode.py`
- 备份数据类型:数据库 `opencode.db`、配置 `opencode.jsonc`、日志 `log/`、快照 `snapshot/`
- 自动探测数据目录与配置目录(多候选位置兜底)
- 数据库采用 sqlite 在线备份 API 保证一致性(WAL 合并)
- 压缩策略:优先 7-Zip,回退 Python zipfile
- 备份目录按日期命名,保留所有历史日期目录
- 编写设计文档(含备份恢复指南)、版本变更、讨论记录
