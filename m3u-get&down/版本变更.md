# 版本变更

## v0.3.0（2026-09-24）

- **站点配置层**：新模块 `sites.py` + 项目根 `sites/` 目录（每站一个 JSON，含
  `_说明` 注释键），按域名匹配加载精修规则：播放页 URL 正则与分组语义、
  线路偏好策略（`line_asc` 线路号优先 / `complete_first` 完整自洽线路优先）、
  集名/标题/简介清洗正则、`failover_max`；未匹配站点回退通用引擎（v0.2.0 行为）。
  内置 `youknow.json` 与 `eacg.json`
- **batch 单集 failover**：每集保留按站点偏好排序的备选线路（alts），
  嗅探/清单/切片失败自动清空工作目录换线重试（默认主线+2 备选），全部失败才标记
- **下载完整性自检**：① 续跑时校验切片文件大小与 progress.json 记录一致，
  截断片自动重下；② 响应 Content-Length 与实际不符按失败重试；
  ③ 合并后 ffprobe 校验（时长>0 且含视频流），失败删坏成品保留现场并报失败
- **单集后处理（get/sniff/play 与 batch 对齐）**：新公共参数 `--keep`（保留现场）；
  默认合并成功后——按站点规则清洗页面标题并重命名成品、扁平到 `downloads/`
  根目录（`-o` 指定目录时不扁平）、删除切片/清单/进度中间产物及空目录；
  get 纯直链无标题保持 output.mp4 仅清理
- **本地验证**：batch 单测 26/26（新增 eacg 坏集表 fixture、failover、站点清洗、
  后处理用例）+ e2e 9/9（新增截断片重下、sniff 后处理、--keep）
- **真站验证**：eacg.net 全流程通过（12 集解析全选完整线路2、简介/封面/广告
  前缀清洗正确、第1集 268.4MB 合并后 ffprobe 通过）；youknow.tv 回归 18/18 跳过
- 修复：complete_first 排序键未接入的 bug（本地测试捕获）；版本号补齐至 0.3.0
- 新增《使用指南.md》：安装/四命令详解/config.json 与 sites/ 配置说明/续跑约定/FAQ记录

> 格式：倒序，最新版本在最上。

## v0.2.0（2026-09-24）

- **统一配置 config.json**：项目根目录，CLI > config > 内置默认；首次运行自动生成
  （含说明键）；新增 `proxy`（requests + Playwright 浏览器贯通）、`download_interval`、
  `insecure` 等字段；requirements 增加 pysocks（socks5 支持）
- **下载进度条**：自写单行刷新条（百分比/切片数/已下载 MB/速度/ETA），
  downloader 与 player_capture 均接入
- **batch 命令（列表页批量下载）**：新模块 batch.py——
  - 列表页两级解析（requests 正则优先，Playwright DOM 兜底），模板分组 + ID 过滤 +
    **按集位去重（线路号升序优先）** + 自然排序
  - 抓简介（剧情/标题/封面 URL 容错修复 + 双重转义实体迭代解码）生成 `简介.md`
    （含剧集状态表，随下载回写）
  - 选集确认（回车全下 / 范围 `1-12,15` / q 退出，`--yes` 跳过；显式范围优先于 --yes）
  - 逐集嗅探+下载，成品扁平为 `downloads/番剧名/集名.mp4`，工作目录集间隔离
  - `批量进度.json` 断点续跑（已完成集跳过）、单集失败不阻塞、集间默认间隔 60s
- **真站实测（youknow.tv 全季 18 集）通过**：约 4GB 成品，18/18 集完成，
  ffprobe 抽验 1080p h264+aac、时长与正片吻合；多次命令超时中断后重跑，
  切片级/集级续传全部无缝接上；单集瞬时失败（CDN 超时/切片 IncompleteRead）重跑自动补齐。
  实测发现并修复：① 列表页为"每线路重复一份集表"结构（346 链接 → 实际 18 集），
  去重策略重设计；② 简介双重 HTML 转义实体；③ batch 子命令 url 参数重复定义；
  ④ `--episodes` 被 `--yes` 覆盖不生效的优先级 bug

## v0.1.0（2026-09-24）

- 初始版本，按《Design/项目设计文档.md》实现：
  - `m3u_down` 包：sniffer / parser / downloader / player_capture / merger / session / cli / utils / config
  - 三种入口：`sniff`（有头浏览器嗅探）、`get`（m3u8 直链下载）、`play`（播放器模式兜底）
  - 切片并发下载（默认 6 线程）+ `progress.json` 断点续传
  - AES-128 解密支持；Widevine/FairPlay 真 DRM 检测并明确报错（退出码 2）
  - ffmpeg concat 自动合并（含 fMP4 init 段、aac_adtstoasc 重试）
  - 嗅探请求头继承（Referer/UA/Cookie）自动带入下载会话
- 依赖：requests、playwright、pycryptodome（requirements.txt）
- **本地全链路验证 6/6 通过**（`本地验证/run_local_test.py`，不依赖真实站点）：
  明文下载 / AES-128 解密 / master 变体跟进 / 断点续传 / DRM 检测 / 嗅探捕获
- **真实站点验证**（youknow.tv，Re:0 第四季第01集）通过：嗅探 → 358 切片下载 →
  合并 1080p h264+aac（24分16秒 / 171.5 MB）；断点续传实测有效（重跑零重下）。
  实测发现并修复 1 个 bug：merger 以输出目录为 ffmpeg 工作目录时，输入/输出
  传了相对路径导致二次拼接找不到文件（本地测试因传绝对路径未暴露），
  修复为 `list_path.resolve()` / `out_path.resolve()`（merger.py）。
