# m3u-get&down 使用指南

> 版本：v0.3.0 ｜ 运行命令统一用 `py`（本机 Python 3.14）
>
> 一个 m3u8 视频嗅探 / 下载 / 合并工具，四种入口：
>
> | 命令 | 用途 | 一句话场景 |
> |---|---|---|
> | `get` | 直接下载 m3u8 直链 | 已经拿到清单地址 |
> | `sniff` | 打开播放页自动嗅探 m3u8 并下载 | 只有播放页地址 |
> | `play` | 播放器模式：模拟在线播放缓存切片 | 页面有复杂加密/需要交互才出流 |
> | `batch` | 列表页批量下载整季 | 整季番剧一次挂机下完 |
>
> 支持 AES-128 加密清单（自动解密）；真 DRM（Widevine/FairPlay）会明确提示并不支持。

---

## 1. 环境要求与安装

```powershell
# 1) Python 3.13+（本机 3.14 已满足），安装依赖
pip install -r requirements.txt

# 2) Playwright 浏览器内核（嗅探/兜底渲染用）
py -m playwright install chromium

# 3) ffmpeg + ffprobe（合并与成品校验用），加入 PATH 即可
#    下载地址 https://ffmpeg.org ；也可在 config.json 的 ffmpeg_path 指定
```

首次运行任意命令会在项目根目录自动生成 `config.json` 默认配置。

## 2. 快速上手

```powershell
# 整季批量下载（推荐）：给番剧列表页地址，交互选集
py -m m3u_down batch "https://www.youknow.tv/d/202678/"

# 脚本化全季下载（跳过确认）
py -m m3u_down batch "https://eacg.net/voddetail/87441.html" --yes

# 只下第 3~5 集和第 12 集
py -m m3u_down batch "https://eacg.net/voddetail/87441.html" --yes --episodes 3-5,12

# 单集下载：只有播放页地址时
py -m m3u_down sniff "播放页地址"

# 单集下载：已从 F12 网络面板拿到 m3u8 直链时
py -m m3u_down get "https://example.com/hls/index.m3u8" --referer "https://example.com/"
```

成品都在 `downloads\` 下：

```text
downloads\
├─ 碧蓝之海第三季\            ← batch 输出（按番剧归档）
│   ├─ 第01集.mp4             ← 成品（扁平，无中间产物）
│   ├─ 简介.md                ← 剧名/封面/剧情/剧集状态表
│   └─ 批量进度.json           ← 批量断点记录（全部完成后可手动删）
├─ 番剧名 第01集.mp4           ← sniff 单集输出（自动清洗命名后扁平）
└─ ...
```

## 3. 命令详解

以下参数四个命令通用（下称"公共参数"），不再重复列出：

| 公共参数 | 说明 |
|---|---|
| `-o, --out DIR` | 输出目录（默认 `downloads/<标题>`；指定后单集不再扁平） |
| `--concurrency N` | 并发下载线程数（默认读 config，6） |
| `--proxy URL` | 代理，如 `http://127.0.0.1:7890` / `socks5://127.0.0.1:1080`（默认读 config） |
| `--insecure / --no-insecure` | 跳过 HTTPS 证书校验（默认读 config） |
| `--keep` | 仅 get/sniff/play：保留中间产物（切片/清单/进度文件），即关闭后处理 |

### 3.1 get — 直链下载

```powershell
py -m m3u_down get <m3u8地址> [公共参数] [--referer R] [--user-agent UA] [--cookie "k=v; k2=v2"]
                     [--quality best|worst] [--variant-index N]
```

| 参数 | 说明 |
|---|---|
| `--referer` / `--user-agent` / `--cookie` | 防盗链站点需要时手动指定请求头 |
| `--quality` | master 多码率清单选流策略，默认 `best` |
| `--variant-index` | 手动指定 master 变体序号（从 0 开始），优先于 `--quality` |

说明：成品固定叫 `output.mp4`（直链没有页面标题可取名），但同样会自动清理中间产物；想改名自己 `Rename-Item` 即可。

### 3.2 sniff — 嗅探播放页

```powershell
py -m m3u_down sniff <播放页地址> [公共参数] [--auto N] [--no-download] [--max-wait 秒]
                     [--quality best|worst] [--variant-index N]
```

工作方式：打开**有头浏览器** → 你在页面里正常点播放 → 工具监听网络捕获 m3u8 候选。

交互命令（在终端输入）：
- `数字`：选择第 N 个候选下载
- `r`：刷新候选列表
- `q`：退出

| 参数 | 说明 |
|---|---|
| `--auto N` | 非交互：出现第 N 个候选时自动选择（挂机/脚本用） |
| `--no-download` | 仅列出候选不下载（找直链用） |
| `--max-wait` | 最长等待秒数（默认 1800） |

成功后自动走与 batch 一致的后处理：按站点规则清洗页面标题命名（如"正在播放《X》第01集[日本动漫] - 某站"→ `X 第01集.mp4`）、扁平到 `downloads\`、清理中间产物。

### 3.3 play — 播放器兜底模式

```powershell
py -m m3u_down play <播放页地址或m3u8直链> [公共参数] [--speed 1~16] [--max-wait 秒]
```

sniff 拿不到流时的兜底：工具在页面里模拟真实播放，旁观浏览器按序接收切片并落盘，播完自动补拉缺失切片并合并。输入裸 m3u8 时会生成本地 hls.js 播放页代播（站点未开 CORS 可能失败，建议给播放页地址）。

| 参数 | 说明 |
|---|---|
| `--speed` | 播放倍速 1~16，如 `--speed 16` 可把 24 分钟的捕获时间压到约 2 分钟 |
| `--max-wait` | 最长等待秒数（默认 7200） |

### 3.4 batch — 列表页批量下载

```powershell
py -m m3u_down batch <列表页地址> [--interval 秒] [--episodes "1-12,15"] [--yes]
                     [--pick N] [公共参数]
```

工作流程：解析列表页 → 抓简介生成 `简介.md` → 展示剧集清单让你确认 → 逐集"嗅探→下载→合并→扁平归档"，每集之间休息 `--interval` 秒（默认 60，对站点友好）。

交互选集：`回车`=全部下载 / `1-12,15`=范围 / `q`=退出；`--yes` 跳过确认。

| 参数 | 说明 |
|---|---|
| `--episodes` | 集数范围表达式（1 基），配合 `--yes`；显式指定时优先于 `--yes` |
| `--interval` | 每集间隔秒数（默认读 config.download_interval=60） |
| `--pick` | 每集嗅探到多个 m3u8 候选时选第 N 个（默认 1） |

内置可靠性机制（无需配置）：
- **单集 failover**：嗅探/下载失败自动换备选线路重试（默认主线+2 备选，`sites/` 配置 `failover_max` 可调）
- **完整性自检**：切片续传校验大小防截断、合并后 ffprobe 校验成品（时长>0 且含视频流）
- **断点续跑**：`批量进度.json` 记录每集状态，**中断后重跑同一条命令**自动跳过已完成集、续传未完成集
- 单集失败不阻塞后续集，结束打印汇总；`简介.md` 状态表随进度实时回写

## 4. 全局配置 config.json

项目根目录，首次运行自动生成；优先级：**CLI 参数 > config.json > 内置默认**。

| 字段 | 默认 | 说明 |
|---|---|---|
| `concurrency` | 6 | 下载线程数（调大提速但更易触发站点限速/封禁，不建议超过 12） |
| `proxy` | `""` | 代理地址，留空不启用；requests 与嗅探浏览器同时生效 |
| `retry_times` | 3 | 单切片重试次数 |
| `retry_backoff` | 2 | 重试退避基数（秒），第 n 次重试等 n×backoff |
| `timeout` | 60 | 读取超时（秒），连接超时固定 15 |
| `output_dir` | `"downloads"` | 输出根目录 |
| `download_interval` | 60 | batch 每集下载间隔（秒） |
| `ffmpeg_path` | `""` | ffmpeg 路径，留空从 PATH 查找（ffprobe 取同目录） |
| `insecure` | false | 跳过 HTTPS 证书校验 |

## 5. 站点配置 sites/

每个站点一个 JSON 文件（如 `sites/eacg.json`），按**域名后缀**自动匹配；没有配置的站点走内置通用解析引擎，一样能用，只是没有精修规则。所有字段均可省略。

| 字段 | 说明 |
|---|---|
| `domains` | 域名匹配列表，如 `["eacg.net"]` |
| `play_pattern` | 播放页 URL 正则，命中的链接才视为剧集页（省略则用通用模板分组） |
| `group` | 正则分组语义：`{"id":1,"line":2,"ep":3}` 指明作品ID/线路号/集位各是第几组 |
| `line_preference` | 同一集位多条线路时的选线策略：`line_asc`=线路号小者优先（默认源）；`complete_first`=集数齐全且"集名序号=集位"的线路优先（专治某条线路集表残缺错位） |
| `label_strip` | 集名尾部噪声正则，如 `"完结$"` 把"第12集完结"清洗为"第12集" |
| `title_subs` | sniff 单集命名的标题替换规则，`[[正则, 替换], ...]` 逐条执行 |
| `desc_prefix` / `desc_suffix` | 简介前后噪声正则（剥广告前缀、"剧情 \| 站名"后缀） |
| `failover_max` | 单集失败时最多尝试的线路数（默认 3 = 主线+2 备选） |

### 加新站点示例

新建 `sites/mysite.json`：

```json
{
  "name": "mysite",
  "domains": ["mysite.com"],
  "play_pattern": "/play/(\\d+)-(\\d+)-(\\d+)\\.html",
  "group": { "id": 1, "line": 2, "ep": 3 },
  "line_preference": "line_asc",
  "label_strip": "(完结|HD)$",
  "title_subs": [["^正在播放", ""], ["_.*$", ""]],
  "desc_prefix": "^.*?简介[:：]\\s*",
  "desc_suffix": "\\s*\\|.*$",
  "failover_max": 3
}
```

不需要时直接删文件即可；写错正则只会该字段失效并打印告警，不影响其他站点。

## 6. 断点续传 / 续跑约定

| 场景 | 操作 |
|---|---|
| get/sniff/play 中途 Ctrl+C 或断网 | **重跑同一条命令**：已下载切片按大小校验后跳过，只补缺的 |
| batch 中途中断 | **重跑同一条命令**：已完成集自动跳过，失败/未完成集自动续跑 |
| 某集总是失败 | 其他集照常完成；失败集保留在汇总里，修好网络后重跑即可单独补 |
| 想看下载了哪些切片 | 加 `--keep`（get/sniff/play）或看 `番剧名\_work\`（batch 进行中） |
| 全部完成后 | 中间产物已自动清理；`批量进度.json` 和 `progress.json` 可手动删 |

## 7. 常见问题

**Q：提示"检测到真 DRM 加密"？**
清单用了 Widevine/FairPlay，密钥在浏览器 CDM 内部申领、明文不经过网络，无法合规获取，工具直接退出（退出码 2）。普通 AES-128 加密不受影响，自动解密。

**Q：sniff 打开页面后一直没有候选？**
先在浏览器页面里手动点一下播放；仍没有试试 `play` 模式。也可以 `--no-download` 先看能不能捕获到直链。

**Q：下载速度忽快忽慢？**
CDN 服务端限速，正常现象。`concurrency` 可适当调大，但别太激进。

**Q：某集提示 Read timed out / 切片下载失败？**
单集瞬时网络抖动。v0.3.0 起会自动换线路重试；若该站只有一条线路，重跑同一命令续传即可。

**Q：批量下到一半 Ctrl+C 了，会白下吗？**
不会。切片级和集级进度都已落盘，重跑同一条命令接着来。

**Q：怎么换下载目录 / 用代理？**
改 `config.json`（全局生效），或单次命令加 `-o` / `--proxy`。

**Q：新出的番剧想持续追更？**
目前做法：隔几天重跑同一条 batch 命令，已完成的集会秒跳过，只下新增集。（自动追更 watch 模式在路线图 v0.4）

## 9. 已验证站点与已知边界

- **youknow.tv**：`/p/{id}-{线路}-{集}/` 结构，线路1 为默认源（line_asc）
- **eacg.net**：`/vodplay/{id}-{线路}-{集}.html`，其"EDD动漫"线路集表残缺错位，
  由 `complete_first` 自动避开；简介源站自带截断属数据问题，工具只剥前缀广告
- 局限：同列表页混多季且集名完全相同时只保留先出现的季，多季番剧请用各季的列表页；
  需要 JS 解密才能取出集表的站点暂不支持（可配 Python 适配器，后续版本再议）
