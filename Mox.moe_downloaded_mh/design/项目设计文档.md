## 章节编号提取规则

### 统一策略

```python
import re

def extract_sort_key(filename):
    """
    从文件名中提取章节编号作为排序键。
    
    策略：
    1. 去掉 [xxx][xxx] 前缀和 .kepub.epub/.epub 后缀
    2. 用正则 re.findall(r'\\d+', name) 提取所有数字
    3. 取第一个数字作为 sort_key
    4. 如果无数字，sort_key = None
    """
    # 去掉 [xxx][xxx] 前缀
    name = re.sub(r'^\[.*?\]\[.*?\]', '', filename)
    # 去掉 .kepub.epub 或 .epub 后缀
    name = re.sub(r'\.(kepub\.)?epub$', '', name)
    # 提取所有数字
    numbers = re.findall(r'\d+', name)
    if numbers:
        return int(numbers[0])
    return None
```

| `卷XX-XX` | `卷001-005.kepub.epub` | 1 |
| `話XX-XX` | `話013-018.kepub.epub` | 13 |
| `話XXX` | `話193-198.kepub.epub` | 193 |
| `第X部第XX-XX話` | `第4部第13-18話` | 4 |
| `第XX卷` | `第01卷巴洛克卷上1.epub` | 1 |
| `第XX冊` | `第01冊：勢如破竹.epub` | 1 |
| `第XX期` | `第01期.kepub.epub` | 1 |
| `XX-XX (无前缀)` | `001-005.kepub.epub` | 1 |
| `XX_名称` | `01_丁丁在蘇聯.epub` | 1 |
| `XX+名称` | `01歌劇院殺人事件.epub` | 1 |
| `名稱-卷XX` | `魔法少女鈴音-卷01.epub` | 1 |
| `卷XX-名称` | `卷08-處女座阿釋密達.kepub.epub` | 8 |
| `全一冊` | `全一冊.epub` | 0 |
| 纯文本无数字 | `TV版特典.kepub.epub` | None |

### 最新章节判定

取 sort_key 最大的文件作为最新章节。显示时去掉扩展名和文件名中的漫画名前缀。

### sort_key = None 的文件

无法提取数字的文件（如 `TV版特典`、`永遠的丁丁`），排序时放在末尾，按文件名字母序。

## 属性提取规则

### 完结状态

从**文件夹名**中提取，优先级从高到低：

| 文件夹名包含 | 状态 | 说明 |
|-------------|------|------|
| `(完)` | 完结 | 如 `IT'SMYLIFE(完)` |
| `(完,缺12)` | 完结 | 如 `變異體少女(未完,缺12)` → 注意这个实际是未完 |
| `(停更)` | 停更 | 如 `學園默示錄(停更)` |
| `(1-7完)` | 完结 | 如 `死都想要你的第一次(1-7完)` |
| `(未完)` | 连载中 | 如 `地下忍者(未完)` |
| `(1-132,未完)` | 连载中 | 如 `金田一37歲事件簿(1-132,未完)` |
| `(未完,缺12)` | 连载中 | 如 `變異體少女(未完,缺12)` |
| 无标记 | 连载中 | 默认状态 |

**注意**：`(完,缺12)` 中"完"在"缺"前面，需要仔细判断。简单策略：先检查 `(停更)`，再检查文件夹名末尾的括号内容是否以"完"结尾或包含"完"。

### 彩色状态

从**文件夹名**中提取：

| 文件夹名包含 | 彩色 |
|-------------|------|
| `全彩` 或 `彩色` | true |
| 其他 | false |

示例：`(全彩版)`、`(全彩簡體版)`、`(彩色版)`、`(簡體全彩版)` 都会被识别。

### 漫画显示名

从文件夹名中去掉以下标记后的文本：
- 状态标记：`(完)`、`(未完)`、`(停更)` 以及其中的附加信息如 `(完,缺12)`、`(1-132,未完)` 等
- 彩色标记：`(全彩版)`、`(全彩簡體版)`、`(彩色版)` 等
- 范围标记：`(1-4)`、`(1-21)`、`(1-90)`、`(1-7完)` 等

## 前端功能

### 首页 (index.html)

#### 表格列

| 列 | 内容 | 排序 | 说明 |
|----|------|------|------|
| 序号 | 自动编号 | ✗ | — |
| 漫画名 | 点击跳转详情页 | ✓ 字母序 | — |
| 最新章节 | 如 "卷003"、"話086-090" | ✗ | — |
| 更新时间 | 如 "2024-01-15" | ✓ 时间序 | — |
| 章节数 | 如 "3" | ✓ 数值序 | — |
| 状态 | 完结 / 连载中 / 停更 | ✗ | — |
| 彩色 | ✓ 或空 | ✗ | — |

#### 搜索

- 页面顶部搜索框
- 实时过滤：输入文字后即时过滤列表，无需点击按钮
- 匹配范围：漫画名

#### 排序

- 点击表头切换排序
- 支持排序的列：漫画名(字母序)、更新时间、章节数
- 升序/降序切换，箭头指示方向

#### 筛选

- 状态筛选：全部 / 已完结 / 连载中 / 停更
- 彩色筛选：全部 / 彩色 / 非彩色

### 详情页 (manga/漫画名.html)

- 页面标题：漫画名
- 章节列表：按 sort_key 升序列出所有 epub 文件
- 每行显示：章节名、文件大小
- 返回首页链接
- 与首页相同的视觉风格

## 技术选型

- **Python 3.13+**: 扫描目录、解析文件名、生成 HTML
- **纯 HTML/CSS/JS**: 前端无任何依赖，纯原生实现
- **JSON 数据嵌入**: 数据作为 JS 变量直接写入 HTML
- **模板替换**: Python 字符串替换生成最终 HTML

## 配置 (config.py)

```python
# 扫描的漫画根目录

# 输出目录

# 章节文件扩展名
```

## 实现步骤

1. 创建 `config.py` - 配置常量
2. 创建 `templates/index_template.html` - 首页模板(带搜索/排序/筛选的完整 HTML/CSS/JS)
3. 创建 `templates/manga_template.html` - 漫画详情模板
4. 创建 `scan_manga.py` - 主扫描脚本:
   - 扫描 MANGA_ROOT 下所有子目录
   - 解析文件夹名提取属性（完结/停更/彩色/显示名）
   - 扫描每个目录内的 epub 文件
   - 提取章节编号和文件大小
   - 计算最新章节和更新时间
   - 生成 JSON 数据
   - 用模板替换生成 index.html
   - 为每本漫画生成 manga/漫画名.html
5. 测试运行并验证
