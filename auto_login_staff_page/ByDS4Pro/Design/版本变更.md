# 版本变更

## v1.2.0（2026-07-20）

- **修复**：
  - 【非触发时间也自动登录】`autoLogin()` 新增 `shouldAutoSubmit()` 判断：仅触发时间或 `doTrigger()` 发起的加载才自动提交；手动访问不登录
  - 【登录后自动刷新退回】新增 `isLoginScreenVisible()` 判断，已登录时跳过；`GM_addValueChangeListener` 只在登录屏幕可见时才刷新
  - 【第二次不点击按钮】改用 `unsafeWindow.login` 获取页面真实 `login()` 函数
  - 【每页面只试一次】用 `sessionStorage._auto_login_done` 标记，同页面生命周期内不重复登录
  - 【连锁反应】`_pendingLogin` 标记配合 `GM_setValue` 跨标签协调，提交后立即清除，防止重复

## v1.1.1（2026-07-20）

- **修复**：
  - 【点击错误按钮】`LOGIN_BTN_SEL` 从 `button` 改为 `#loginScreen button`，DOM 中 Login 按钮前有 4 个 toggle 按钮，`querySelector('button')` 会点击第一个 toggle 按钮而非 Login

## v1.1.0（2026-07-20）

- **修复**：
  - 【触发不可靠】新增 `startPeriodicCheck()` 每 30 秒轮询兜底，防止后台标签 `setTimeout` 节流失效
  - 【登录按钮不点击】`tryLoginNow()` 改为四重策略依次尝试：`window.login()`（优先级最高）→ `btn.click()` → `dispatchEvent` → 密码框 Enter
  - 【按钮选择器不匹配】`LOGIN_BTN_SEL` 从 `button[onclick="login()"]` 放宽为 `button`
  - 填入凭据后触发 `input` 事件，让前端框架（React/Vue 等）感知值变化

## v1.0.0（2026-07-20）

- **功能实现**：
  - 工作日 9:00 自动打开 `网址`
  - 已有标签页时强制刷新弹出登录框
  - 自动填入用户名密码并点击登录
  - 当天只触发一次，错过不补
  - 周末自动跳过
- **技术方案**：`setTimeout` 一次性定时器 + `GM_setValue` 跨标签防重复 + `MutationObserver` 表单检测
- **配置方式**：脚本顶部常量区可调整触发时间、凭据、选择器
