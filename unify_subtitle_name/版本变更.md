# 版本变更记录

## v1.0 (2026-07-06)

- 初始版本
- 实现三种文件名对齐模式：number（数字序号）、sequential（顺序匹配）、fuzzy（模糊匹配）
- 实现 `--dry-run` 预览模式
- 实现扩展名自动规范化（补前导点号、忽略大小写）
- 实现数量不匹配警告、目标冲突跳过等边界处理
- 创建项目设计文档.md
- 零外部依赖，仅使用 Python 标准库

## v1.1 (2026-07-06)

- **修复已对齐字幕导致后续配对偏移**：在配对前预过滤已存在同名字幕的视频/字幕对，只对剩余未对齐部分执行对齐策略
- **新增备份机制**：重命名前在 `sub_bak/` 目录中以原始文件名备份字幕文件（`shutil.copy2`，保留元数据）
