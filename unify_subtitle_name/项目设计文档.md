# 项目设计文档 — unify_subtitle_name

## 一、项目概述

| 项目 | 说明 |
|------|------|
| 项目名称 | unify_subtitle_name — 视频与字幕文件名统一工具 |
| 运行环境 | Python 3.6+ |
| 外部依赖 | 无（仅使用标准库） |

**设计目标**：扫描指定目录下的视频文件和字幕文件，按对齐策略将字幕文件名逐一改为对应视频文件的名称，方便播放器自动识别挂载。

## 二、用法

```powershell
python main.py <视频扩展名> <字幕扩展名> [--mode number|sequential|fuzzy] [--dry-run]
```

**示例**：

```powershell
# 将 .srt 字幕与 .mp4 视频按数字序号对齐
python main.py .mp4 .srt

# 按模糊匹配对齐，仅预览不实际执行
python main.py .mkv .ass --mode fuzzy --dry-run
```

## 三、参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `video_ext` | 位置参数 | 必填 | 视频文件扩展名（如 `.mp4`、`.mkv`），可省略前导点号 |
| `sub_ext` | 位置参数 | 必填 | 字幕文件扩展名（如 `.srt`、`.ass`），可省略前导点号 |
| `--mode` | 选项 | `number` | 对齐模式：`number` / `sequential` / `fuzzy` |
| `--dry-run` | 标志 | false | 仅预览重命名结果，不实际执行 |

## 四、目录结构

```
unify_subtitle_name/
├── 项目设计文档.md
├── 版本变更.md
└── main.py          # 主脚本
```

脚本在当前工作目录下执行，扫描该目录下所有匹配扩展名的文件。

## 五、三种对齐模式

### 5.1 number（数字序号对齐）— 默认

从文件名中提取所有数字序列，转换为整数元组作为排序键，分别排序视频列表和字幕列表，按顺序配对。

**适用场景**：文件名格式规范，包含集数序号（如 `S01E01`、`EP01`、`第01集`、`01.xxx`）。

**提取示例**：
- `S01E01.mp4` → `(1, 1)`
- `第03集.mp4` → `(3,)`
- `Episode_10.mp4` → `(10,)`

### 5.2 sequential（顺序匹配）

按自然排序（字母 + 数字混合排序，`1,2,...10,11` 而非 `1,10,11,...2`）分别排序后，按顺序 1:1 配对。

**适用场景**：文件名无统一数字格式，但双方排序顺序一致。

### 5.3 fuzzy（模糊匹配）

对每个视频文件，遍历所有未匹配的字幕文件，用 `difflib.SequenceMatcher` 计算文件名相似度，选择相似度最高的配对（阈值 0.3）。

**适用场景**：视频与字幕文件名差异较大，但整体上存在可匹配的相似片段。

## 六、核心逻辑流程

```
开始
├─ 解析命令行参数
├─ 校验扩展名格式（补前导点号、转小写）
├─ 扫描当前目录获取视频列表和字幕列表
│   ├─ 视频列表为空？→ 报错退出
│   └─ 字幕列表为空？→ 报错退出
├─ 根据 --mode 选择配对策略
│   ├─ number    → 提取数字 → 分别排序 → zip 配对
│   ├─ sequential → 自然排序 → zip 配对
│   └─ fuzzy     → 为每个视频找最佳匹配字幕
├─ 遍历配对结果
│   ├─ 字幕已与视频同名？→ 跳过
│   ├─ 目标文件名已存在？→ 跳过
│   ├─ --dry-run？→ 仅打印，不执行
│   └─ 否则执行 os.rename
└─ 输出统计结果
```

## 七、边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 视频数与字幕数不一致 | 按配对数量裁剪（number/sequential），多余文件忽略并输出警告 |
| 扩展名未带前导点号 | 自动补充 `.` |
| 文件名大小写不同 | 比较时忽略大小写 |
| 目标文件名已存在 | 跳过该文件并提示 |
| fuzzy 模式无匹配 | 配对为 None，跳过，输出警告 |
