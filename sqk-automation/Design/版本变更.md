# 版本变更

## v0.2 (2026-09-20)

从"若干独立脚本"改成"有编号的操作集合 + 统一入口"。**破坏性变更**：入口脚本全部收敛到 `main.py`。

- 新增 `main.py` 唯一入口：`list` / `info <编号|名称>` / `run <选择器>`。
- 新增 `framework/`（与 adb 无关的调度骨架）：
  - `registry.py`：自动发现 `automations/` 下的操作；校验编号/名称唯一、名称字符合法
  - `selector.py`：支持 `2`、`screenshot`、`1-5`、`[1, 3, 5]`、`1,3,5`、`1 3 5`、`all`
  - `runner.py`：按序执行，默认跑完整串再汇总；`--fail-fast` 立即停止
  - `context.py`：操作运行上下文（设备、参数、日志）
- 新增 `automations/`：一个文件一个自动化操作。`connect.py`（编号 1）、`screenshot.py`（编号 2）。
- 新增 `config/params.json`：操作参数，每个操作读自己那一段；键名写错运行时会提示。
- 新增 `config/number_ledger.json`：编号台账，编号一经使用永不复用；改派编号会直接报错。
- 新增 `.gitignore`：忽略 `__pycache__/` 与 `screen_shot/*.png`。
- 文档统一移入 `Design/`。
- 参数取值：`--open` / `--no-connect` 从命令行迁到 `params.json` 的 `screenshot` 段
  （`open_after` / `reconnect` / `show_info`）。
- 删除 `connect.py`、`screenshot.py`、`adb_kit/cli.py`；`一键截图.bat` 改为调用 `main.py run screenshot`。
- `selftest.py` 从 11 项扩到 60 项，新增注册表、台账、选择器、参数合并、序列执行的覆盖，
  以及一次走 `main.py` 的端到端截图自检。

### 顺带修复

- `adb_kit/adb.py` 的 `device_info()` 读系统属性写成了 `shell ro.product.model`，
  这不是合法的 shell 命令，会被 except 吞成"未知"，所以 `connect` 操作里的型号和安卓版本一直是未知。
  改成 `getprop ro.product.model` / `getprop ro.build.version.release`。
  真机验证后显示 型号=ross、安卓版本=14、分辨率=1920x1080。
- 属性读不到（空输出）时显示"读不到"而不是空白，避免再出现"看起来成功其实没数据"。
- 统一操作内日志缩进（此前 `连接 →` 与 `型号：` 两级缩进不一致）。

## v0.1 (2026-09-20)

首个版本，建立基础设施。

- 新增 `config/devices.json`：电视盒子设备信息（名称 / IP / 端口），支持多台设备与默认设备。
- 新增 `adb_kit/` 核心包：
  - `config.py`：配置文件加载与路径常量
  - `adb.py`：adb 命令封装（可用性检查 / connect / devices / shell / 截图），统一 `-s host:port` 寻址；exec-out 截图失败时自动回退 `screencap + pull`
  - `screen.py`：截图文件命名与落盘
  - `cli.py`：入口脚本共用的 `--device` / `--config` 参数
- 新增 `connect.py`：连接设备并打印型号 / 安卓版本 / 分辨率；`--list` 列出配置中的设备。
- 新增 `screenshot.py`：连接 + 抓取盒子当前屏幕，保存到 `screen_shot/日期_时间.png`；支持 `--no-connect`、`--open`。
- 新增 `一键截图.bat`：一键截图入口。
- 新增 `selftest.py`：离线自检（假 adb），覆盖连接、截图、CRLF 还原、pull 回退、命名、落盘共 11 项。
- 新增 `.gitattributes`：强制 `*.bat` 使用 CRLF（LF 批处理会被 cmd 错行解析）。
- 新增 `项目设计文档.md`、`讨论记录.md`。
