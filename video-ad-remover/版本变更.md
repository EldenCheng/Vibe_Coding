# 视频广告移除工具 - 版本变更

## 版本历史

### v1.0.0 (2026-09-09)

#### 初始发布
- **功能**:基础广告检测和移除
- **格式**:支持MP4格式
- **处理**:CPU快速复制模式
- **检测**:基于PTS不连续点自动检测

#### 新增功能
1. **自动广告检测**
   - 使用ffprobe获取PTS值
   - 检测最大时间戳跳跃
   - 自动定位广告位置

2. **快速复制处理**
   - 使用`-c copy`不重新编码
   - 处理速度极快
   - 保持原始视频质量

3. **批量处理支持**
   - 支持通配符匹配
   - 支持多个文件同时处理
   - 显示处理进度和结果

4. **灵活输出选项**
   - 自动生成`_clean`后缀
   - 支持指定输出目录
   - 保持原始文件不变

### v1.1.0 (2026-09-09)

#### 功能增强
- **新增格式**:支持TS (MPEG-TS) 格式

#### 改进
- 优化PTS值解析,提高稳定性
- 改进错误处理,提供更清晰的错误信息

---

### v1.2.0 (2026-09-09)

#### GPU加速支持
- **新增功能**:NVIDIA GPU加速 (`-g`)
- **编码器**:支持h264_nvenc硬件编码
- **参数**:使用`-preset fast`和`-cq 23`

#### 技术改进
- 重构编码器选择逻辑
- 支持CPU和GPU模式无缝切换
- 添加GPU可用性检测

#### 使用示例
```bash
# CPU模式(默认)
python remove_ad.py "*.mp4"

# GPU模式
python remove_ad.py "*.mp4" -g
```

## 已知问题

### v1.0.0 - v1.3.0
1. **广告时长假设**:默认假设广告不超过30秒
2. **单段广告**:只支持检测和移除一段广告
3. **PTS依赖**:依赖视频的PTS时间戳准确性
4. **格式限制**:只支持ffmpeg支持的格式

### 解决方案
- 使用`-d`参数调整广告时长阈值
- 等待未来版本支持多段广告
- 确保视频文件未损坏
- 检查ffmpeg版本和编解码器支持
