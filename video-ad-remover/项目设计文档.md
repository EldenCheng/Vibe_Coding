# 视频广告移除工具 - 项目设计文档

## 项目概述

这是一个Python脚本工具,用于自动检测并移除视频文件中的广告片段。该工具针对被篡改的MP4/TS视频文件设计,这类文件在中间插入了广告,并通过PTS(显示时间戳)不连续来限制用户跳过广告。

## 问题背景

### 问题描述
从某些网站下载的视频文件(如牙狼系列),在视频流中嵌入了广告片段。这些广告:
1. 物理编码在视频流中,不是独立的流或overlay
2. 广告前后存在PTS时间戳跳跃(通常约270秒)
3. 播放器无法跳过广告,因为中间的内容被删除了
4. 用户必须等待广告播放完毕才能继续观看

### 技术分析
通过ffprobe分析发现:
- 视频帧的PTS值存在不连续点(跳跃约270秒)
- 广告内容被物理插入到视频流中
- 原始内容(约5分钟)被删除
- 示例:原始视频从5:23跳到9:55,中间4.5分钟内容缺失

## 解决方案

### 核心思路
1. 检测PTS时间戳中的最大跳跃(不连续点)
2. 在跳跃点之前移除指定时长的内容(广告)
3. 保留广告前和跳跃后的正常内容
4. 将两段内容拼接成完整视频

### 技术实现
- **检测算法**:遍历所有PTS值,找到最大的正向跳跃
- **剪切方法**:使用ffmpeg的`-ss`参数在输入之前,提高精度
- **拼接方法**:使用mpegts格式和concat协议
- **编码选项**:支持CPU快速复制(`-c copy`)和GPU加速(NVENC)

## 功能特性

### 核心功能
1. **自动广告检测**:基于PTS不连续点自动定位广告
2. **快速复制处理**:使用`-c copy`不重新编码,处理速度极快
3. **GPU加速支持**:可选使用NVIDIA NVENC硬件加速
4. **批量处理**:支持通配符匹配多个文件
5. **灵活输出**:可指定输出目录或自动生成`_clean`后缀文件

### 参数说明
| 参数 | 说明 | 默认值 |
|------|------|--------|
| `files` | 视频文件或通配符 | 必需 |
| `-d, --duration` | 广告最大时长(秒) | 30 |
| `-o, --output-dir` | 输出目录 | 与源文件相同 |
| `-g, --gpu` | 使用GPU加速 | False |

## 使用方法

### 基本用法
```bash
# 处理单个视频
python remove_ad.py "视频文件.mp4"

# 处理多个视频(使用通配符)
python remove_ad.py "*.mp4"

# 处理TS文件
python remove_ad.py "牙狼*.ts"
```

### 高级用法
```bash
# 指定广告时长
python remove_ad.py "*.mp4" -d 25

# 指定输出目录
python remove_ad.py "*.mp4" -o "cleaned/"

# 使用GPU加速
python remove_ad.py "*.mp4" -g

# 组合使用
python remove_ad.py "牙狼*.mp4" -d 30 -o "cleaned/" -g
```

## 技术细节

### 依赖要求
- Python 3.x
- FFmpeg 4.0+ (需要在系统PATH中)
- FFprobe (需要在系统PATH中)
- NVIDIA显卡驱动(如果使用GPU加速)

### 文件格式支持
- MP4 (H.264/H.265)
- TS (MPEG-TS)
- 其他ffmpeg支持的格式

### 处理流程
1. 使用ffprobe获取视频所有帧的PTS值
2. 计算相邻帧的PTS差值
3. 找到最大的正向跳跃(不连续点)
4. 计算广告开始点(不连续点 - 指定时长)
5. 使用ffmpeg剪切两段视频:
   - 第一段:从开始到广告开始点
   - 第二段:从不连续点到结束
6. 将两段视频拼接成最终文件

### 编码选项
**CPU模式(默认)**:
- 使用`-c copy`快速复制
- 不重新编码,处理速度最快
- 保持原始视频质量

**GPU模式**:
- 使用`-c:v h264_nvenc` NVIDIA编码器
- 使用`-preset fast`快速预设
- 使用`-cq 23`恒定质量因子
- 需要NVIDIA显卡和支持

## 输出说明

### 文件命名
- 输入: `视频文件.mp4`
- 输出: `视频文件_clean.mp4`

### 处理结果
- 广告被完全移除
- 视频时长减少(通常减少25-30秒)
- PTS时间戳连续,无跳跃
- 视频质量保持不变(CPU模式)或接近原质量(GPU模式)

## 错误处理

### 常见问题
1. **未检测到广告**:视频没有PTS跳跃,自动跳过
2. **剪切失败**:检查ffmpeg是否正确安装
3. **拼接失败**:检查临时文件是否生成成功
4. **GPU不可用**:检查NVIDIA驱动和ffmpeg NVENC支持

### 调试信息
- 显示检测到的跳跃大小和位置
- 显示移除的时间范围
- 显示使用的编码模式(CPU/GPU)
- 显示处理成功/失败状态
